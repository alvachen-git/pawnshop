# 客人离场反馈 · 2026-09-06

已接待或已在等候的客人因耐心耗尽、轮次用尽、等候到期或关门离场时，展示独立纸页，包含人物、货物、原因、收尾回应和操作耗时。阅读与收起不推进时间；未成交时不显示收付款凭据。

一次操作造成多人离场时合并为一页，逐人的原因可滚动查看。尚未见到的未来来客不因提前关门逐个弹窗。主动拒收沿用原反馈，成功成交沿用成交页；同一操作同时成交和导致其他等候客人离场，先展示成交页，再展示离场页。关闭消息后恢复库存、风险说明等先前页面。

实现是接待历史的界面观察器，不改价格、耐心、轮次、流水或存档格式，不新增议价自动存档。读取、重开、回滚会清除临时通知，重复状态刷新不会重新通知。正式危机、事件及终局优先。

## 排队离场歧义修正 · 2026-09-06

用户截图显示第2夜20:20、周绍安仍在柜台、最近结果为超时离场。只读核对其本地夜初检查点的种子42和来访编排：周绍安19:25到店、20:55离场；排队的沈文清19:45到店、20:15离场。在隔离存档用同种子真实推进营业钟复现，证实排队客人超时，当前客人仍可交易。原弹窗统一写“未能成交”，匿名最近结果进一步混淆了离场对象。

现在保留行动开始前的接待身份快照，排队客人超时使用“等候客人离场”，写明尚未轮到柜台；标明离场者、当前仍在接待的人，按钮为“继续当前接待”。收起后保留当前交易页。当前客人确实谈崩时才显示相应“未能成交”，清掉其接待入口。柜台最近记录显示发生时间、姓名和结果，不显示上一夜的匿名结果。
