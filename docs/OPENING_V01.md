# 开场剧情占位版

依据提供的《鬼市当铺_开场剧情脚本_V0.1.docx》与实现清单，并按 `PLAYER_COPY_GUIDE.md` 调整玩家可见文案。目标是验证从人物动机进入真实经营的节奏，再确认第一夜房间收尾成立。

## 试玩

双击项目根目录的 `试玩开场.cmd`，或在 Godot 中打开 `scenes/opening.tscn` 按 F6。现有默认入口保持原样；开场入口有自己的新游戏与读取按钮，存档为 `user://p0/opening_v01.json`，不覆盖原版本存档。

1. 纱厂扣工钱 → 姚曼卿旧照片与婚帖 → 顾敬堂遗信 → 看货、看人、当票三段回忆 → 接铺。
2. 四个柜台热点可自行选择顺序。看过明账和红黑旧册后，点「坐上柜台」，再在营业面板开铺。
3. 第一位街坊妇人带银簪。点物品进入鉴定，观察后快速鉴看；也可询问来历，再通过正式报价成交。
4. 成交单先显示现金和入库结果；点击盖章出现红印与音效，再收好凭据。交易提交只有一次，盖章不重复扣款。
5. 库存中的银簪可以交给街口银楼。后续客流照常进行；送走第一位顾客也不会卡住游戏。
6. 正常关门、等到03:00、结清息费，然后上楼。放信、看灯、可选择摆照片或看镜子；收拾妥当后，点击床并确认就寝。
7. 首夜没有梦境、索命与镜面惊吓。睡眠片段后等到天明，可继续第二夜经营。

开场文本点击推进，无强制等待。8–10分钟是首位顾客到柜的设计上限，真实首次阅读时间仍待负责人试玩确认。

## 当前实现范围

| 内容 | 做法 |
| --- | --- |
| 剧情调度 | 现有 EventDirector + RunDefinition.event_ids，数据优先级排列；不另建 OpeningManager |
| 占位演出 | NarrativeScene 只负责显示、按钮和声音，冷灰纱厂、旧照片、婚帖、信与钥匙、暖色回忆、外景与房间剪影 |
| 进店热点 | 同一事件的可重复选择；已看热点不重复授予状态，明账金额读取实际费用规则 |
| 正式交易 | AppraisalSystem、CounterService、TradeController、EconomyManager、InventoryManager 与既有成交单 |
| 教程保护 | CustomerVisit 对应来访的 tutorial 数据设最低报价次数和耐心，不修改报价接受条件 |
| 数值 | 数据配置：初始100银元；借据本金300，每夜利息3、铺面开支5。示范收购21、银楼卖出28，可实现毛利7，未扣当夜息费 |
| 首单失败 | 可送客或谈崩；下一笔真实收购后的确认事件补齐 INTRO_FIRST_TRADE_DONE，不用拒价返回值判断成交 |
| 遗信与照片 | 来信及钥匙等拥有状态由事件旗标表示，不混入可售库存；遗信入抽屉后可完整回看，摆下照片后房间保留查看入口 |
| 保存恢复 | 开铺前每个选择、房间互动和睡眠片段均校验后原子保存，失败整段回滚；旗标由历史选择重建 |
| 多周目 | 到过铺内后记录本地 meta；新周目才显示跳过，逐一执行原零耗时选择以补齐状态，保留进店与真实交易 |
| 中文文本 | 开场事件使用稳定文本键；`text_zh_CN.json` 是可编辑文本，编译为 Godot Translation |
| 音效 | 自制合成的机器、纸张、钥匙、门、钟、盖章与楼板占位音效，无外部录音依赖 |

## 保存边界与后续开发

营业中的即时交易沿用现有工程的夜末检查点规则，不支持任意报价中途退出后原地继续。开场前半段可「保存并退出」；交易期间关闭程序会回到上一开铺前检查点。原有存档编码版本未提高，新增字段都是内容侧可选项。

目前用独立三夜配置验收开场，没有把整段序章强行接入主入口或七夜内容。后续确认节奏后，再将事件清单并入目标 RunDefinition，并对对应全流程存档与经营平衡验收。

建议下一轮先看三件事：玩家能否理解主角把铺子当作翻身机会；顾敬堂是否像可信长辈；第一单之后是否想继续做生意。节奏确认后再替换纱厂、人物、信件与外景正式美术，以及真实拟音和转场。

## 内容与验证入口

- `data/opening/`：事件、运行、银簪、顾客、银楼与中文文本。
- `tools/create_opening_content.py`：当前数据的可重建作者源；修改后会重写上述内容文件，手工改 JSON 时不要再次运行生成器。
- `tools/build_opening_translation.gd`：将中文 JSON 编译成 `.translation`。
- `tools/create_opening_audio.py`：重建合成占位音效。
- `tests/run_opening.gd`：正常路线、反序热点、拒客后补首单、真实现金库存、保存恢复、篡改拒绝与失败回滚。
- `tests/opening_ui_smoke.gd`：真实鼠标点击、两个窗口尺寸、盖章遮挡、长信滚动、取消/确认就寝与多周目跳过。
