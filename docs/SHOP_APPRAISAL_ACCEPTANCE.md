## 经济与尚待试玩事项

| 情形 | 折扇计价基数 | 时间及费用 |
| --- | --- | --- |
| 未升级、未送行家 | 20 | 无专业投入 |
| 二级台及工具，初始名声，自判真作 | 31 | 设施累计150银元；两处合计20分钟 |
| 同上，自判临摹 | 23 | 同上 |
| 同上，自判后添款 | 20 | 同上 |
| 名声升至8，自判真作 | 53 | 需要先前多件行家验证；不能重复验证同件累积 |
| 行家复核 | 按实际类别75／35／20 | 每件6银元、20分钟；保留既有服务 |

表中为计价基数，不是最终售价或净利润；原渠道系数、来源加价与陈列买家的实际报价继续适用。当前自鉴的核心用途是收购前参与判断，并用已有名声有限争取认价，不能宣称少量折扇即可收回150银元投入。两次比对需要20分钟，正好耗尽客人期限则无法完成最后证据。

本批没有买家售后验证或追索系统，主动虚报真作仍可能比保守判断获得更多即时回款；这项激励、名声权重、工具费用与工期需继续试玩后讨论。尚未进行跨大量种子的全经营经济平衡，不能把上述功能验证当作经济平衡通过。陈列来客概率及旧销路系数均未调整。
