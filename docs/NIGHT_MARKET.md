## 新增体验

| 时段 | 氛围及交易 |
| --- | --- |
| 18:00–21:00 | 人市：铺内及街面较亮，台灯关闭 |
| 21:00–00:00 | 黑市：铺内与街道明显变暗，台灯点亮；可能遇到只听一次正式报价的卖家 |
| 00:00–02:00 | 阴市：街道与四周接近隐没，仅留下灯下近景；可能遇到抱湿包的卖家 |
| 02:00–03:00 | 禁时：远处更深黑，近处光域收紧；湿包成交后较容易留下麻烦 |

每夜仍为六位基础潜在新客，准备行动及原当户按已有规则额外安排。普通席位尽量按四档 2/2/1/1 分布；主线、熟客、活当和钢笔预约席位优先保留。一局四个不同夜晚安排两位一次报价卖家、两位湿包卖家。第一夜不安排特殊夜客，不强迫玩家接待或拖到深夜。

一次报价卖家允许鉴定、普通问话、收购或拒收，只能正式报价一回，不另行施压或活当。货物沿用现有怀表、钢笔品相；低要价不是获利保证，仍需识货。

湿包卖家明确交代“来处莫问”，货物沿用青花碗、砚台及其品相。成功成交可能仅有惊吓，也可能留下货物异常或个人纠缠；问了禁忌问题，即使随后拒收，也会留下个人异常。后果在开局固定，查看界面、读档不会重抽。

在营业页处理留下的包布，耗时20分钟、不花钱。柜前有客、原当户待办或剧情未决时，先处理眼前的事情；营业或关铺后均可封存，最迟恰好在03:00完成。处理只对应那一块包布，不消除铜镜后果，也不恢复已经损失的货物。

货物异常未及时处理时，只损失对应现货；成本记损失，不再扣一遍现金。个人纠缠不会随卖货消失。命灯在首次沾染时泛青，随后未处理的每个就寝夜晚再恶化一步，多项来源不会在同夜连续跳档。最后一个来源处理完才恢复这部分影响。将熄时先有明确警示；熄灭进入独立失败记录。第七夜按真实状态结束。

## 建议试玩

1. 先随意开一局，比较四个时段的背景、台灯与客流；长时间看界面应不耗游戏时间。
2. 种子0：第二夜可遇到一次报价卖家，第四夜可遇到湿包卖家。比较重点鉴定后报价、报价过低离场、主动拒收。
3. 湿包收购后分别试“及时封存”和“留下不管”，查看库存、夜末账目及房间命灯。再试问来处后拒收，确认后果不会随离场消失。
4. 种子4：第三夜就有湿包机会。连续不处理可验证后续命灯警告和终局；若提前关门错过机会则不补刷。
5. 21点前确认台灯不发光，21点后确认开灯；午夜后仍能打开库存、账本与鉴定页，证据图片和金额不应一起变黑。回房、读档及新一夜开铺后，光照应跟随真实时刻恢复。
6. 非营业阶段保存、退出再读回，检查包布、现货、命灯和费用一致。旧档照常可读，营业中仍不能保存。

## 光照与美术交接

依负责人试玩反馈，新增的全部环境声、播放器及音量控件已移除；本轮不动原有开场与操作声音。四档氛围改由现有铺景的曝光、冷暖、台灯开关与局部照明区分。21点前灯泡无发光，21点后柜台保留一片暖光，午夜及2点后逐步压暗远景。

人物及柜台物品适度随环境压暗，鉴定证据、对话纸张、金额和菜单保持清楚。沿用现有背景资产做光效草图，不更换场景布局、交互热点或最终美术。旧内容保持原来的视觉规则，新版旧存档无需迁移，重新打开即按保存的时刻显示。
