## 时段与安排

| 客人 | 到店时间 | 出场夜次 |
| --- | --- | --- |
| 毡帽客 | 22:00—23:30 | 第2—7、8—12、13—18夜各一次 |
| 抱包客 | 22:30—00:00 | 第4、8、15夜，后两次需前次不验货且买下 |
| 湿包客 | 23:00—01:00 | 第2—18夜随机一次 |
| 提匣客 | 23:00—01:00 | 第5—12夜满足原条件时每日20%，实际出现后不再来 |

- 普通客仍有深夜时段。特殊客不会更换主线、熟客或已预留的预约来客。
- 时间以本局种子和客人、夜次决定，记录到原有特殊客计划；重复查看、刷新和读档不重抽。
- 新时段为绝对钟点，赎当办理造成的普通来客延迟不会把特殊客推到时段之外。安排时计入普通客的赎当延迟，优先间隔15分钟；繁忙时使用不重叠的5分钟位置。
- 提匣客需实际到柜前时也在窗口内；超过01:00不转成提匣客，也不消耗当夜抽签。
- 抱包客前两次成功成交时告别：“下回我还夜深了来。掌柜，莫太早落闩。”交易禁忌、失败中断和军方停业顺延保持原规则。

## 独立存档与启动

最新启动器指向 `scenes/start_special_guests_late_v46.tscn`，配置 `data/special_guests/run_late_v46.json`、内容版本46、特殊客规则版本3。存档库为 `user://special_guests_v46/library.json`，回退存档路径为 `user://special_guests_v46/autosave_v46.json`。未增加存档字段。

v44、v45的配置和场景保持原样，旧局沿用旧时间，不追溯更改；新时间规则需从v46入口开始新局。v45仍可从 `scenes/start_special_guests_wet_v45.tscn` 打开其原存档库。

正常试玩：

```powershell
& "D:\CodexData\runs\pawnbroker-special-guests\play-special-guests.cmd"
```

直接查看湿包客（独立测试预置，不保存）：

```powershell
& "D:\CodexData\runs\pawnbroker-special-guests\play-special-guests.cmd" -Stage wet -Wide
```

`-Stage hat` 是22:00的毡帽客，`-Stage bundle` 是22:30的抱包客，`-Stage wet` 是23:00的湿包客。`bedroom`、`bedroom-aged` 可测试异响和第五夜压力，预置时钟用于快速核对，不代表自然局固定在整点生成。去掉 `-Wide` 使用1280×720，加上使用1600×900。
