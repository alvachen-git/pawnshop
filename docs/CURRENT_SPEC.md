## 第一账当前流程

1. 第十夜收铺留陈阿福当票存根；第十一夜凤镯进入普通生意；第十二夜起陈小满以绣片生意来访。交易完成后才认物，不在交易中插入案件。
2. 实际读过铺内存根、陈家原票、出货凭据及凤镯工记与修补，才能正式核实归属。原票约七夜，初五已售、初六来赎；不是改票骗过当户。
3. 陈小满提起祖父遗留的双窝镯匣，说明还缺龙镯。答应后开放寻找；暂缓可再谈，直接赔偿仍独立可选。读完回应后她离场。从这次选择起，陈小满只在开铺前选择“约陈小满来谈”后再来（共用准备1次，不另收费）；无预约不自动来访。受邀后的归还、赔偿、暂缓或拒绝回应结束即离场，当天不重复出现。
4. 开铺前“托人寻找龙镯”耗一次准备，不收费，每局成功一次。当夜核账、危机处理后，回房前收陆掌眼的消息；提前收铺仍可收到，死亡终止后续。
5. 后续开铺前“约陆掌眼带龙镯来”耗一次准备；19:00起空柜接待。首次谈价按当时商誉：非负150、负值200。该会面内锁价；另日重约才重新报价。
6. 买入耗5分钟，扣现金、唯一龙镯入库和动作历史原子提交。暂缓不扣商誉，回应读完自动离场。普通错过须花一次准备重约；军方停业自动顺延，不再消耗准备。
7. 两只真实金镯归还记“清”；知情商谈后付300记“和”。两者互斥。军方庇护与隐秘购货支出仍为可查资料，不强加结案门槛。阴账联系与结案回响保留；不揭露阿七身世。

旧当铺册页保留已知口信供复查，不新增任务面板或进度条；打开册页不会自动获知未读证据。阿七十一夜以后继续陪伴，22:00及提前收铺时离开，闲聊不耗时。
