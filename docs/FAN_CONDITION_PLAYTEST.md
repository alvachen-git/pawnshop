## 现在如何玩

1. **柜台查品相**：折扇原来的识货、细看、复检和通用判断按钮已移除。固定的“检查破损 · 5分钟”无需鉴物台，自有现货也可从库存检查。
2. **鉴物台辨真假**：“送上鉴物台”需要二级专用台、扇画工具和顾砚生知识。无需先检查破损；两处手记可免费改选，只有确认落笔扣10分钟。
3. **分别看记录**：品相、自己的判断、行家复核与来源分别显示；对客说法留在交易页。未查品相不显示完整参考价值，不再显示折扇旧的17–83区间。
4. **发现破损再谈价**：检查只让你知道破损，不会自动改变客人要价。选择具体破损说法后，再正式报价成交。

| 实际品相 | 保留价值 | 据实破损让价 |
| --- | --- | --- |
| 完整 | 100% | 无破损让价 |
| 轻损 | 80% | 当时要价与底价各降20% |
| 重损 | 50% | 当时要价与底价各降50% |

品相与真假独立，暂用60%／30%／10%的生成权重。重读、翻页和检查不重抽。货物本来就有破损；检查前后实际卖货价值一致。

破损谈价每客一次，耗5分钟及一轮议价，适用于**收购和活当**。判假压价另有一次机会，仍只适用于**买断**，并与普通贬低共用机会。两种说法可按任意顺序使用；每次基于当时金额取整，因此顺序可能产生1银元差异。已开出的当票不改价。

品相折价先于买家报价倍率和来源溢价，只算一次；杂货回收商、陆掌眼和陈列买家共用这一口径。破损让价不改自鉴结论、不增减鉴定名声，也不单独扣商誉。原有判假压价及其隐藏商誉规则继续有效。

## 升级与知识（2026-09-22补充）

二级鉴物台与扇画工具不再要求先找到工具册。鉴物台页面只列当前等级、已有能力与当前阶段可办理的操作；费用、准备消耗和必要禁用原因保留。

| 步骤 | 条件与花费 |
| --- | --- |
| 整修一级台 | 第二夜起，开铺前；40银元、1次准备，当晚可用 |
| 改造二级台 | 已有一级台；80银元、1次准备，两夜工期；无需工具册 |
| 添置扇画工具 | 二级台完工；30银元、1次准备；无需图录 |
| 学习顾砚生知识 | 第二夜起、开铺前点击旧账柜第一柜，再点“学习顾砚生知识”；1次准备，不收费，无需先探索或找到工具册 |

知识按领域和对象分别记录。这批只有书画领域的“顾砚生知识”，放在左上方第一柜；柜面不写名字，鼠标移上去柜门发亮，点击后查看知识。掌握后可在同一柜免费复看要点。它只用于顾砚生扇画，不等于掌握所有书画、瓷器或机械知识。以后可为其他对象配置独立知识与柜位。

没有掌握顾砚生知识时，可以修台、买工具、检查破损、正常交易，也能收货后请行家鉴定；暂不能自行比对他的扇画。二级台、工具和知识三项齐备后，才可“送上鉴物台”。学会知识不会自动给出真假答案，仍由玩家圈点、比对和落笔。

本补充直接适用于已有v29存档，无需重开。旧局已经研习的直接认作掌握顾砚生知识，不再扣准备；只找到册子但没研习的，仍须到第一柜学习。v27、v28继续沿用各自原有升级与学习条件。查铺三步继续是独立探索，不受知识学习影响。

## 时间与经营取舍

检查和破损谈价都必须在客人离开、03:00之前完成，恰好到期不能开始。既有待办、禁忌、轮次与耐心限制保留；禁止验货的客人仍会收货离开。

固定样本中，轻损扇两种让价后收购成本从28降到13银元，卖给回收商收到15银元。但晚到的重损扇，多谈一轮可能赶不上当晚出货，必须占款到次夜。折价并不保证每笔转售赚钱，详见[验收与经济对照](FAN_CONDITION_ACCEPTANCE.md)。
