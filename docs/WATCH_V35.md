# v35 怀表谈价 · 本地试玩

2026-09-23。本次只改百达翡丽猎壳金怀表。统一入口新游戏采用独立 v35；v34及更早的客人、试听、举证与定价保持原规则。未推送、未发布。

## 直接启动

PowerShell 可在任意目录使用完整路径：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\play-unified.cmd" -Stage watch -WatchCase partial -Wide
```

这是隔离测试预置，银钱、器材和客人已备好，不保存到正式存档。依次点击当物 → 鉴定 → 器材鉴定 → 凝神听音；立即停止也会留下记录。手记可以保留未定项，落笔成功直接回柜台。

然后进入交易 → 商量价钱，勾选本次要谈的问题，选择对客说法，再提交。手记中的明确判断会默认填入，可改口，不覆盖手记。每次提交耗5分钟、1轮；每类问题每位客人只能提交一次。

| `-WatchCase` | 情境与建议操作 |
| --- | --- |
| `partial` | 真表换姿态停顿；点一下试听，提出“换姿态停顿”，客人认下但只让一半价差：385→347 |
| `firm` | 同样货况；客人认下运转问题，仍要385 |
| `fault` | 同样货况；客人愿足额让出价差：385→308 |
| `fake-fault` | 正常真表；试听后谎称“中途停走”，客人会相信并按故障货估价：385→193，实际货值仍500 |
| `exposed` | 正常真表；直接谎称“仿制或冒名”会被拒，并扣商誉；要价不变 |
| `bargain` | 原主低估真表；指出真货不会自动抬价 |
| `overpriced` | 原主把仿表认作名表 |
| `urgent` | 急用钱，初始要价已经让过15%，后续不会重复套用这项折扣 |
| `guide` | 开铺前，到第二柜翻阅《名表鉴定指南》 |
| `natural` | 保留随机客人认识与性格；可搭配原有货况参数 |

`spotted`、`bluff`旧参数继续可用，分别对应会拒绝虚假说法、会相信虚假说法的预置。省略 `-Wide` 使用1280×720；加上后为1600×900。

正式新局运行同一路径，不带 `-Stage` 参数。存档库按运行隔离自动位：`auto/watch_negotiation_ten`；独立自动文件为 `user://watch_negotiation_ten/autosave_v35.json`。

## 本版规则

- 试听开始前先保存当前上弦状态和姿态，保存失败不播放；播放结束不再记第二次。重复点击同一种试听不增加依据。
- 身份和修配可以不检查就说；运转至少点击过一次试听；外观只允许引用检查出的事实。
- 身份、修配的依据按机芯观察0/1/2处划分；运转按上弦后试听过0/1/2种姿态划分，时长不参与判断。
- 相信概率采用确认的三档表；独立固定随机值随客人保存。完整且正确的依据必被承认，是否让价仍取决于性格。
- 好商量35%、谨慎45%、强硬20%。分别让全部、50%、0%的价差；急用时为全部、75%、25%。
- 目标价按客人相信的身份、修配、运转与已知外观计算；从来访初始要价和底价重算价差，结果不超过当前价格。仿冒价不再叠加修配折扣，活当筹款线163不变。
- 被相信的假话只改变客人认识；库存出售、盈亏、真实货值不改变。公开估值不因假话收窄，高价奖励也不采用虚假依据。
- 同次多项不被相信只扣一次耐心；不实说法被识破商誉−2，每位客人最多一次，仍受每日负奖励上限约束。属实但说服失败只损耐心。
- 每类说法用过即锁定，补查、改口、读档均不恢复机会。提交内容、相信的货况、逐项回应与处罚记录独立保存。

代码入口：`core/shop/watch_negotiation.gd`；独立内容由 `tools/build_watch_negotiation_content.py` 从冻结的v34生成。实机截图及测试结果见 [验收记录](qa/watch-v35/REPORT.md)。
