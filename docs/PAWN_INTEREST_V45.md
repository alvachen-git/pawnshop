## 玩法与界面

| 档位 | 三夜整期息费 | 利息商誉 | 普通客人与富客赎回率 |
| --- | --- | --- | --- |
| 低 | 5%，向上取整 | 成交 +2；该次来访报过高息则不奖励 | 原概率 +10 个百分点 |
| 中 | 10%，向上取整 | 无额外变化 | 原概率 |
| 高 | 20%，向上取整 | 首次通过校验的正式报价 −2，同次来访不重复扣 | 原概率 −10 个百分点 |

- 本金评价仍结算；本金与利息评价共享每夜正、负各6点上限。
- 刚硬或不急用钱的客人拒绝高息，扣正常报价时间、轮次和失败报价耐心。本金要价不因此降低，可改中低息再谈。
- 沈季安、Edward 刚硬；周锦生、李衡、程玉笙、姜素云可商量。普通人物按种子与人物 ID 固定25%刚硬。富客优先沿用已有急用钱状态，没有时使用独立固定30%序列。
- 第一、二夜隐藏活当，直接命令也拦截；普通、富客及准备招来的顾客不生成只当不卖组合。
- 第二夜陆掌眼登门与来信卖货保留。第三夜开铺前再次登门，使用人物立绘、底部短页对白和独立回应，分三段讲解；每段回应后保存，告别解锁。收起后点人物继续，不耗时间或行动点。
- 报价区横向三档单选，实时预览本金、三夜息费、赎金及到期夜次；同客刷新和重开保留选择，新客默认中息。高息不会按后台态度预先禁用。
- 急用钱与高息态度不再自动显示在交易页。通过对话询问“这笔钱何时要用？”后才记入口供；普通客人复用原问题，富客补齐选项，每次5分钟，不扣议价轮次或商誉。回答与正式报价拒绝使用相同判定数据；不显示商誉值或赎回概率。
- 姜素云只比较实际筹款与合同赎金，提前取赎全额结清；未筹够时保留卖绣品筹款路线。

## 存档与实现边界

集中政策：`core/pawn/pawn_interest_policy.gd`。`counter_command("pawn", visit_id, tier, principal)` 的 `detail` 接收 `low/medium/high`；v45严格校验，旧版本仍接收原格式。

新票记成交档位、票面赎金与最终赎回合同。随机数由本局种子和来访 ID 固定，成交时结合档位计算。存档通过既有完整命令历史重放重建，校验当票、首次高息、低息奖励、解锁与商誉；不信任修改后的票面金额或赎回结果。

保存失败回滚状态与未发布通知，覆盖报价时间、耐心、轮次、钱款、当票及商誉。v45额外为提前赎回／约定到期再来补上检查点；旧版本保存行为未更改。

## 建议试玩顺序

1. 开新局，第一、二夜确认没有活当入口；第二夜照常听陆掌眼介绍来信卖货。
2. 第三夜开铺前听活当教学，试收起后点击人物继续，告别后开铺。
3. 找可活当客人，在对话中问“这笔钱何时要用？”了解其用款与息钱态度，再切换三档报价。交易页只保留合同信息和实际报价回应。
4. 在账本查看固定票面，到期验票收赎；无人来赎时在夜末选择留货或转当。
