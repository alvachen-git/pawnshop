# 德国徕卡Ⅰ型相机 · v43 本地试玩

基于 main 80c3282，独立分支 codex/camera-appraisal-v43。本轮尚未推送或合并。

## 启动

在 PowerShell 中执行完整路径，无须先切换目录：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\.artifacts\camera-appraisal-v43\play-unified.cmd" -Stage camera -Wide
```

默认是镜片雾化样本。测试预置不保存正式进度，已配好二级台与知识。点击柜台上的相机，选择鉴定，再进入器材鉴定。

可在末尾添加 `-CameraCase good`、`haze`、`scratched`、`sticky`、`stuck`、`rebuilt`、`imitation`、`no-tools`、`partial`、`firm`、`exposed` 或 `guide`。`natural` 使用自然生成货况。

持有人可加 `-Holder silk|factory|opera|antique|comprador`，分别为周锦生、李衡、程玉笙、沈季安、Edward。不加时暂用沈季安。正式新局不加 `-Stage camera`。

## 已实现的玩法

- 新局用相机替换精品绣屏的货位，保留十种高档货。所有富客均能携带，首版沿用该货位的携货权重：25 / 5 / 10 / 5 / 5%。内部物品 ID 沿用旧货位，旧存档仍加载旧物品定义。
- 柜台检查外观 5 分钟；器材鉴定 10 分钟，需要二级及以上台、放大镜、灯、相机知识。不重复购买专用器材，不设深入查验。
- 铭文与镜座、镜片、光圈、快门四组操作；可移灯、放大、改变光圈开度、过片上弦、切换快门挡位并按动快门。之后操作免费，重复操作不累计依据。
- 第四柜加入《洋相机鉴定指南》，替换该局绣谱。首次学习用一次准备，不收钱；第二柜名表指南、其他指南位置不变。
- 身份、镜片、机械运转分别落笔，可保留暂难判断。任何进度都可落笔，成功后回柜台；手记不再改写，对客说法可不同。
- 上弦前按快门不动作；上弦后顺畅、迟滞、卡住有不同的动作和点击间隔。可视帘幕用于观察开合，不模拟曝光测量，也不生成照片。
- 客人对每类问题只接受一次提交，一次或合并提交耗 5 分钟及一轮。延续现有识货、急迫、信任、让价比例与识破惩罚。承认但不让价时会区分原价已算入、坚持价钱、筹款线等原因。
- 开始查验、操作、落笔、举证统一走现有事务与动作日志。写盘失败回滚，试快门保存失败时不播放。

## 首版平衡数值

这些数值为游戏平衡，非历史售价。

| 固定事实 | 状态 | 数值 |
|---|---|---|
| 型号身份 | 原装 / 拼配改装 / 仿制冒名 | 基础货值 800 / 480 / 120 |
| 镜片 | 清透 / 雾化 / 划伤 | 70 / 20 / 10%；保留 100 / 80 / 65% |
| 机械 | 顺畅 / 迟滞 / 卡住 | 70 / 20 / 10%；保留 100 / 80 / 50% |
| 外观 | 完好 / 轻损 / 重损 | 原 60 / 30 / 10%；保留 100 / 80 / 50% |

实际货值 = 身份基础值 × 镜片比例 × 机械比例 × 外观比例，最后四舍五入。机械故障另固定落在光圈、快门或两处；不会重复扣价。识货和急迫沿用现有独立随机规则。所有随机事实与说法结果保存后固定。

初始柜台范围 39—800，外观查明后按外伤比例调整；手记与客人被说服不收窄区间。出售统一使用固定实际货值。高价商誉参考仅使用真实且被承认的问题。

李衡活当筹款线 260，Edward 为 300；买断无筹款线。等候、开价、底价、耐心、赎回均取实际持有人参数。

身份依据：看铭文镜座为中，放大查看后为强。镜片依据：看一处光照为中，至少两个光照位置为强。机械依据：尝试至少两个光圈开度、上弦后按快门各提供一项依据。强依据提高说服力，不自动纠正玩家的判断。

## 历史与美术边界

以 1925 年推出的 Leica I 为年代基础，黑漆机身、镍饰与伸缩镜头营造民国进口相机感觉。依据：[Leica 官方时间线](https://timeline.leica-camera.com/en/years/1925)。图样为游戏美术化样本，不作为逐零件复原或真实鉴定标准。

镜片雾化、划伤、装配差异及叶片迟滞可观察；单凭铭文、反光或声音均不能保证真伪。未加入胶卷、冲洗、维修及曝光精度测试。

## 铭文与快门音效修订

冒牌新增三款拼写差异，与旧 LIETZ 共四款。货物生成时独立、等概率抽取并固定保存；已有相机缺少新字段时保持旧图，不在查看时抽签。身份变化只改变图样，价格规则不变。

可用 `-CameraCase imitation-legacy`、`imitation-letters`、`imitation-extra`、`imitation-city` 分别查看四款，`imitation` 按固定种子选择。标准参考仍为 ERNST LEITZ / WETZLAR。

快门已改用 CC0 的 1935 年 Contax 相机实录（非 Leica I 实录），保留正常快、慢挡的实际音色。迟滞与卡住使用同源录音剪辑，已撤下自制合成音。详见 assets/camera_desk/audio/SOURCE.md。用 `-CameraCase good`、`sticky`、`stuck` 对比；先过片上弦，再按快门。
