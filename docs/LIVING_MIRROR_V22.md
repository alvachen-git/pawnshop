# 泣血铜镜 v22：辨生死与两类阴客

2026-09-12，本地内容修订，基于 v21 商品复核七夜版。新游戏入口为 `mirror_living_seven`，使用独立 v22 自动存档；旧局从存档目录按原内容继续。原有商品、赎回概率、熟客、行情、开铺准备与寝屋改动保留。

## 试玩与规则

菜单入口为「物品记事」，按已知物品名称选择记录；未接触的物品不提前列出。铜镜页分为「照看与处置」和「物品见闻」：前者提供覆红、揭布、照客及调查行动，后者只保留已有短记、调查线索与镜中旧事，不列出照客使用记录，也不显示复看耗时提示。读完短记后自动显示见闻页，全文只展示一处；售镜后仍保留已取得的记录。《绝当录》仅在已有实际死亡记录时出现，作为独立条目，不与物品见闻混排。此调整不改变行动耗时或存档结构。

第三夜收镜后，在柜前或「物品记事」选择「借铜镜照看来客」。镜面须揭开；每次5分钟，可连续使用。同一来访的结果稳定，照客结果在当次操作时显示。普通来客、丈夫、两类阴客、到期及提前赎当者都适用。活人留影，亡魂无影；镜子不提供品相、底价、善恶或接待禁忌。未接待者不会自动识别。

覆红与揭布免费；正常照客不招祟。售镜、覆布、时间不足、剧情或危机尚未处理时不能照客。若五分钟内来客离场，时间仍消耗，只记未完成辨识。

第三夜丈夫仍是活人。「看镜中旧事」为独立5分钟行动，先看到母子梳妆的日常，再转入典镜求药；追看另花5分钟，事先有香灰折断、倒影回身的预警。它与通用照客不共用次数。女性旧事残影不替代来客本人的生死结果。第三夜药费客按普通问话、议价规则接待。

| 来访 | 玩法与时间 | 玩家可以据此决定什么 |
| --- | --- | --- |
| 第四夜不许验货的来客 | 使用原搬家样板客位，每局一次。可以问话、问来源、议价、照客、拒收，只卖断；实际鉴定或核验凭据与实物会消耗原动作时间，客人当即带货离开，不留下鉴定结果 | 已知对方是亡魂，也可以遵守规矩成交。货物是普通货，品相按种子决定，不能靠开场文字猜定好坏 |
| 第五至第六夜提匣人 | 23:00后首个合适普通客位；有尚在铺内的普通活当才出现。不会覆盖熟客、指定活当、预约、准备锁定或已经透露的来访 | 原物属于他人，替物外观相似却异常冰冷，来客还额外付钱。镜子只证实来客非活人，决定做不做这笔生意仍在掌柜 |

提匣人按种子固定点名一张合格当票，选择不参考隐藏赎回结果，复看和读档不换目标。接受或拒绝均5分钟，可以先照客。接受后一次收80银元，原物交出，独立替物放入原票保管位置；本金、赎金、期限与原主赎回概率不变。只能成交一次，无议价；拒绝不受罚。没有合格当物或合适客位，沿用预先生成的普通客人，不在七夜外补刷。

以下为验收剧透：到期或提前赎回时实际交付替物，原主于下一日死亡，下一次开铺前收到一次消息，记入「铺中记事」。针对具体人物停止后续来访，不杀死同职业的其他人，不增加亡魂回访。未赎回、只续当、未完成交付均不触发死亡。无人赎回后留货或转当沿用原规则，效果不扩散给同行或后续买家。第七夜交付后的死讯仍待发生，不提前播报或开启第八夜。

## 章节边界

当票10分钟 → 街坊证词15分钟 → 身份链15分钟 → 两册矛盾10分钟 → 动机旁记10分钟，保持原有开放顺序。街坊先叙她的劳动、养育与求生，再交代母子死讯。卖镜、从未用镜、错过货郎仍可查现实资料。

顾先生保留铜镜，是为保留辨认阴客的经营保障。作者设定按 GDD V0.9：顾敬堂确已死亡，其亡魂已抵押；本章玩家文案不提前泄露这一主线内幕。七夜只确认丈夫身份、顾先生隐瞒与动机，记录继续调查／暂时封存／继续使用三种阶段态度。丈夫后续调查、正式镜前对质、女主人离去和能力失效均未开发。寝屋旧镜仍是另一物品。
