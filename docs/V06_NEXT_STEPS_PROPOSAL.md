## 第二阶段：七夜经营循环

### D1 新债务系统

初始本金独立配置，暂为300银元。日期与比例独立配置，不硬编码应付金额；不提供提前或部分还本。

| 节点 | 规则 | 初始300时 |
| --- | --- | --- |
| 第21夜 | 付足初始本金40%，或整笔延期；有钱也可主动延期 | 支付120或0 |
| 第49夜，首期已付 | 偿清真实剩余本金 | 180 |
| 第49夜，首期延期 | 全部本金＋初始本金20%延期费 | 300＋60 |
| 第49夜未清 | 不再延期，破产并记入《破铺录》 | 终局 |

首期及延期费向上取整；尾款使用真实剩余本金，避免多收。延期费仅第49夜收取，不生息、不复利。

铺费每日5；利息每日1%，按当夜开始时剩余本金向上取整。还本从次夜降低利息：300的日息3，第21夜还120，第22夜按180收2；延期仍日息3。

每夜夜末先补旧息费短款，再支付当夜息费，然后处理到期本金。日常短款只宽限到次夜夜末，届时未补齐破产；本金延期不能抵消日常违约。本金支付只影响现金及负债，不记经营费用；利息、铺费、延期费分别入账。

借据开局说明金额、日期、延期代价；账本分别展示日常短款与本金义务。七夜结束保留真实债务和短款期限，不提前催收，不宣称结清。

交付债务状态、流水、界面与保存；21/49夜用财务测试夹具覆盖付款、主动延期、无钱延期、尾款与失败。另测更换本金后的比例/舍入及还本当夜/次夜分界，不扩写49夜剧情。

### D2 准备行动及行情

第四夜正式开放，每日最多2次：调查消息、联系买家。查看已知资料免费，可主动结束准备。先做一条跨夜行情链，消息改变实际需求或报价，产生急售回款与持仓等待的取舍。行情真相与玩家已知信息分开保存，读档不重抽机会。

### D3 事件与信息

扩展现有事件导演以支持房间阶段、必要的跨夜顺延和主线保底。复用标记与历史，只为本批内容增加明确状态变化接口。商业材料归铺中，私人材料归书桌，按已知程度展示。

先以少量内容跑通七夜，确认资金占用、买家机会与每日成本确实产生选择，试玩评审后扩量。

## 第三阶段：慢热七夜内容

| 夜次 | 主要体验 |
| --- | --- |
| 1 | 接铺、借据、旧掌柜信件、第一次收购 |
| 2 | 识货与识人，买入和出售的差别 |
| 3 | 活当、资金占用、熟客与沈怀川 |
| 4 | 准备行动、行情消息、第一次持仓选择 |
| 5 | 姚曼卿婚讯或旧物，建立私人动机 |
| 6 | 铜镜进入交易，轻微且未解释的异象 |
| 7 | 可选铜镜收益提示、账目回顾、阿七与铺鉴抽屉钩子、回房就寝、最终摘要 |

Demo只做一件铜镜，第7夜可有一次转化成交易优势的异常提示，不直接说明原理或识鬼能力。只展示存放线索及轻微个人异常，不开放原型致命追看分支。拒收/卖镜仍可完成主线，仅可能错过额外收益。完整知阴与严重索命留到后续。第7夜没有本金催收。

普通交易逐批扩充，每批先验收不同判断问题，再补数量。沿用此前数量方向：普通物品约15–20种、特殊来源约3–5种、顾客约5类，但不作为单批硬门槛。关键NPC为沈怀川、陈小满、阿七；姚曼卿先通过婚讯和旧物存在。可疑来源承担识人、估价和取舍，不提前开放黑市势力。20–30个事件是后续生产批次，不要求全部进入一局七夜。

美术按布局、图层、热点、证据解锁接口先确认再制作，接入已有12张交易图需求、房间背景、必要人物和关键异常。多数房间夜晚安静，变化克制。玩家文案遵循 PLAYER_COPY_GUIDE.md，操作、金额、期限明确，剧情不泄露答案。

## 验收与延期范围

- 财务：日常短款補齐/破产、21夜两种延期及付款、49夜两种应付额/失败、配置本金与舍入、息费与本金记账分离。
- 保存：回房/危机/就寝/日结跨进程恢复，重复点击、写盘失败/重试不重复扣款或归档，旧文件不被覆盖。
- 剧情：早关门、长时间鉴定、拒镜不意外卡核心节点，第7夜没有本金催收。
- 体验：玩家能说明报价依据，至少有一次持仓取舍，感到鬼货有价值且不对劲。
- 交付：每阶段包、说明、验证；双分辨率、Windows完整试玩。七夜90–150分钟为待验证目标，不靠重复交易补时长。

完整鬼市、七笔阴账、并蒂红契、六势力成长、49夜剧情暂不制作。
