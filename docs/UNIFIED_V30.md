# 完整整合运行 v30

2026-09-22。本地分支 `codex/unified-gameplay-v30`，基于已同步的 main `fc90ece`。本次将已实现的独立功能接入同一新局，尚未推送；客人类别拓展另行规划。

## 启动

双击仓库根目录 `play-unified.cmd`，或在 Godot 中运行项目。两者都进入 `scenes/start.tscn`，标题页新游戏使用 `unified_ten`，十夜、内容版本30。

正常启动与编辑器共用系统用户目录中的档案库；快速试玩与 `-Verify` 使用隔离目录，不覆盖正常进度。新局使用自动位 `auto/unified_ten`，独立路径 `user://unified_ten/autosave_v30.json`。

```powershell
.\play-unified.cmd
.\play-unified.cmd -Stage introduction
.\play-unified.cmd -Stage fan -Wide
.\play-unified.cmd -Stage plaque
.\play-unified.cmd -Stage companion
.\play-unified.cmd -Stage call
.\play-unified.cmd -Stage reunion
```

快速试玩先通过真实流程生成并校验对应存档，因此首次进入需等待测试完成。其他阶段：`contract`、`upgrade`、`informed`、`ordinary`、`urgent`、`no-bench`、`intact`、`minor`、`major`、`stack`、`delivered`、`bedtime`、`dream`。

## 联动规则

- 军方事务占用随机强事件通道；统一局中不会因此屏蔽有条件的主线调查、阿七线索或托梦。各剧情自己的前置与互斥规则继续生效。
- 送礼、修缮、学习和既有准备共用每夜两次准备额度。孙大元初次接待未完时不能开铺或进入设施操作。
- 军牌压价按九成向上取整，折扇判假与破损让价按各自原规则计算；按实际操作顺序逐次取整，同时更新购买与活当各自适用的价格。军牌不消耗议价轮数，每位客人限一次，口碑减少1。
- 真实瑕疵与已查实的破损折价会降低口碑评价的公平价格基准。军牌强压不会降低该基准。
- 把真扇说成假货并因此低价买入，原折扇记录的口碑处罚现在同步到统一局的实际口碑，按配置扣2且只记一次；通常交易的低价处罚仍独立计算。鉴定名声继续单独记录。
- 新增关系变化、交货、接待与压价进入原子保存和行动回放。写盘失败还原银元、物品、关系、时钟与行动记录；伪造关系分数或重复借牌记录会被拒绝。

## 客人拓展的起点

下一步基于这一份统一运行讨论客人，而不再按独立试玩版本分别规划。现有维度分别是普通职业模板、生计与交易意图、熟客身份、夜客规则、剧情人物和军方特殊来访；口碑影响可替换普通客流，准备影响邀约，剧情与特邀使用专门规则。新增类别应先明确属于哪个维度、适用货物、议价差异、可占用时段、出现权重和与保留剧情位的关系。

本次未增加新的客人类别或改动八类职业的基础抽取权重。
