# 成交信息页 · 草图实现与检查

2026-09-05。按负责人截图反馈实施：成交成功后独立显示信息页，增强钱货交割的反馈。负责人补充要求先做草图，未来由美术负责人整体规划；本次沿用现有主题和物品图，不制作精细美术、不打试玩包。

## 行为

- 收购、活当、出售、赎当、续当成功后出现居中的成交凭据。标题、物品、实收/实付、现金前后变化、货物去向分层展示。
- 收购不提前展示真值或获利，出售才显示真实已实现盈亏；活当展示到期夜、约定赎金和在当状态。
- 玩家主动点击“收好凭据”或Esc继续；也可直接查看库存/当票。查看和关闭不耗时、不重复交易。没有顾客时不再保留无效报价表单。
- 以新产生的交易流水判定成功，不使用返回值ok或文本匹配判断；低价被拒、钱不足、重复旧交易都不产生新凭据。
- 待读事件/关键危机在凭据关闭后优先恢复。铜镜收购后继续展示存放规矩。新局、读取或阶段切换不残留旧凭据。
- 这是表现层反馈，不增加保存节点、存档字段、交易费用或营业耗时。
