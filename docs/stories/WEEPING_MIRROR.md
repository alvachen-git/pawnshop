## 2. 作者真相与流转

以下按相对先后排序；不新增绝对年份或人物姓名。

1. **嫁妆与成家。** 母亲把铜镜交给女主人。她用它梳妆，也从镜里看孩子长大。至少通过一段生活记忆呈现她曾经的安稳，不能首次出现就只有受难画面。
2. **丈夫离家。** 丈夫生意受挫，带走剩余钱财，声称出去另谋生计。他后来重新做起买卖，具备写信或回来的条件，却因不愿面对失败、家庭负担与自己的过错而不联系妻儿。没有失忆、被囚或暗中接济的反转。
3. **撑住生活。** 女主人先做浆洗与缝补，收入不足后被迫进入风月场。镜子一直由她珍惜保存。记录她劳动、养育和主动求生的行为，不把从事妓业作为过错或死亡原因。
4. **为药费典镜。** 孩子病重，她立即拿出最后舍不得的嫁妆。顾先生正常收当；她反复确认能否当日取钱，最后才问还能否赎镜。票角“留”意为到期暂缓出卖，等她回来。顾先生当时尚未见过镜的异能，不能写成以治病相要挟谋取鬼货。
5. **母子死亡。** 孩子仍未获救。女主人在长期困苦、丧子和孤立中自尽。正文不用具体方法、死亡场面或职业羞耻强化刺激。丈夫当时没有主动打听，也未尽到联络与照顾责任；不能无证据写成他亲手害死二人。
6. **异能出现。** 女主人死后，铺里的铜镜开始渗出暗红痕迹。她未得到回答的疑问，化为镜对交易者“为何舍下”的追问。顾先生通过普通交易逐渐证实能力可以帮助压价与识别处境。
7. **顾先生认出丈夫。** 丈夫曾到铺中做生意，铜镜首次明显泣血。顾先生没有只凭异象定论，而是通过原主旧资料、货郎经历和留下的联系方式核实身份。随后继续与他有商业往来，却在铜镜资料旁写“无从追查”，把有用地址留在另一册收货账中。
8. **刻意维持。** 顾先生担心她得知答案、停止等待后能力消失，主动压下调查。他没有把真相带到镜前，也未促成对质。其过错是死后的知情隐瞒和利用，不直接改写为造成母子死亡。这个动机有独立的使用笔记支持，不由玩家仅凭一句账目矛盾推断为事实。
9. **流出与返回。** 顾先生离开当铺后，铜镜随旧物清理流入市场，由第三夜售镜人带回。售镜人口述与清理记录只证明流转，不证明顾先生去向，不发展出他被镜所害的新设定。
10. **玩家接手。** 玩家可以先从能力获益，再理解它的来历。货郎重临使镜中旧事与眼前人重叠，展开第一章。

## 3. 当票、泣血与危险的含义

当票记下的是现实交易：铜镜、当款、期限及药费缘由。附记保留家庭关联信息，使它能和货郎旧交易材料核对，但“同姓”或一张相似面孔不足以确认身份。

“留”字有两个不同阶段：生前是暂缓出卖的允诺；死后顾先生继续留镜是为了收益。不能把前一次善意倒写成他从一开始便预谋利用她。

普通窥镜时，镜缘有淡红痕迹、断续哭声。认出丈夫或听见其否认时，镜中女人眼下出现血泪。血从镜面里面渗出，不靠新增伤口或展示死亡方法解释“泣血”。

货郎到来时铜铃正常响。异常先是倒影的衣袖和动作不同，继而露出女人与旧柜台，明确提示异常来自镜子。丈夫的真实身份最终靠资料核实，不靠铜镜给出“负心人”标签。

红布已覆时，被动异象只写布角鼓起、布缘沁红等外部变化，不透视布下的倒影或旧票。玩家需要按原成本揭布才可见镜面；揭布本身不等于主动窥镜，不额外授予深层片段。完全没有揭布也能沿现实材料调查。

镜内保留的是无法结束的旧事。普通窥镜只看一瞬；在倒影转身、香灰折断的预警后继续追看，观看者可能被卷进旧事，自己的影子被留在镜内。这解释了危险为何跟随掌柜，不写成女主人任意报复协助调查的人。

“这笔还认不认”前期可指向当票，后期逐渐指向丈夫是否承认妻儿。夜间一句回应不偷偷构成认债、解咒或对最终结局的选择。铺内未覆红风险与个人追看风险仍区分；正常查资料、正常窥镜不会自行产生新的随机索命。

## 4. 能力规则与经营样板

### 4.1 使用、知识与收益

| 规则 | 本次确定的设计 |
| --- | --- |
| 对象 | 持有仍具能力的铜镜、营业中有配置专属片段的卖家在柜前，镜面已揭开 |
| 次数与成本 | 每夜主动窥镜一次、5分钟；覆红、揭布均不耗时，不占主动窥镜次数。额度随夜次更新，存档重载不恢复 |
| 已知次数 | 顾先生使用笔记说明每夜只显一回，使用后的镜面不再回应；必要功能提示直接显示已用状态，不让玩家盲试扣时 |
| 无适配对象 | 不生成通用读心结果，不扣次数或时间；查看功能说明免费 |
| 片段稳定性 | 同一局同一来访结果固定；再次读取记录免费，不要求持镜，也不再次获得收益 |
| 含义边界 | 片段反映交易缘由的一部分，不能自动证明急售、撒谎或品相；更不能显示底价、全部记忆或远处人物 |
| 追问与优惠 | 影像开放具体问题；核实后才接已有处境／矛盾议价规则。相同原因共用收益组，先问普通问题再窥镜也不多获一次优惠 |
| 危险边界 | 普通使用仅有轻微异常，不设跨夜怨气累计；仅配置了危险后续的剧情节点可以主动追看，另花5分钟并先预警 |
| 被动异象 | 不占主动额度。第三夜见到泣血疑点不依赖主动窥镜；深入查看仍占一次，额度用完就转现实调查，不赠送第二次主动使用 |
| 失败与离客 | 没有足够游戏时间或前置不满足时不启动；已启动并实际流逝时间后客人离开，保留本次耗时和额度，记录中只出现实际看见的内容 |

额度是使用规则，追看是一次已开始窥镜的危险延续，不构成第二次获得交易情报。普通问题、物品检查、自由报价与提前成交始终可用。新增情境不自动套用怀表急售5银元优惠；沿用对应交易已有规则，具体绑定在后续实施时单列配置。

### 4.2 两种专属体验

以下确定内容意图，不在本轮指定或改动运行里的普通来访编号。

| 样板 | 镜中片段与表面说法 | 核实与收益 | 错误理解的纠正 |
| --- | --- | --- | --- |
| 证实急售处境 | 客人说是闲物，镜里出现药铺柜前反复清点的钱与等候的人 | 追问今日是否必须付药钱，对方给出可核对的票据和时间；可使用该情境已有的一次让价机会 | 影像本身不证明货有故障；不能据此再压一次品相价，也不将现实中的女主人故事复刻成同一个NPC |
| 影像存在歧义 | 客人说价不合就带走，镜里出现收好的行李 | 追问得知只是搬住处，仍有时间卖货；没有急售优惠 | 强行催价沿用对应普通客的耐心代价；玩家学会把片段当作问题线索，而非答案 |

第三夜先提供样板一的体验机会，第四至第五夜提供样板二。玩家可以不使用或错过，故事不把两次使用作为身份调查门槛。片段文字不透出隐藏数值。

### 4.3 解开心结后的能力

女主人离去后永久失去窥镜能力，不奖励升级版异能。镜子仍是有来历的普通旧物，保留其物件价值；新的异能与鬼货存放风险来源停止，已触发的当夜危机必须先处理，不能通过结局回滚。最终仪式安排在没有未决危机的节点，不强迫玩家同时应对结局与旧追看。

下表中的 `WM-E` 编号是文档引用，不是已实现的证据标识。旧档中已有的一次“窥镜”记录不能自动授予这些新事实。

| WM-E02 泣血与倒影 | 第三夜货郎在场且玩家持镜时被动发现，或主动窥镜取得更多片段 | 此人使镜子有异于普通使用的反应；出现衣袖差异与旧票 | 不是丈夫身份或犯罪判决；未遇到也可从典物记录查起 |
| WM-E03 当票存根 | 由镜背典物特征查铺中旧当册，核对存根；不要求看清镜内票号 | 嫁妆镜、筹药费、家庭关联与顾先生所写“留” | 原主不来赎不等于死亡；镜已售出但留有观察记录仍能比对；无记录只能保留未证实来历 |
| WM-E04 原主生活及死讯 | 从存根所记旧住处找到当年的邻人，取得其见证；与旧当册的后续记事对照 | 她曾靠浆洗缝补养家，后来进入风月场；孩子病逝，她随后自尽；确认典当时间早于死讯 | 邻人不知丈夫异地全部经历，也不讲述自尽方法；调查作为可重访材料入口，不要求赶上一位随机卖家 |
| WM-E05 货郎身份链 | 货郎旧交易中的家庭旧住址及其本人叙述，与WM-E03／04比对；可记录第三夜口供作旁证 | 眼前货郎与原主丈夫是同一人 | 单凭同姓、模样或泣血不够；错过第三夜，可沿顾先生旧收货账找到固定联络人，核实仍在使用该地址的货郎身份，不虚构本局成交记录 |
| WM-E06 可联系却“无从追查” | 取得身份链后，对照顾先生收货账中的联络地址、再次交易日期与铜镜资料的结论 | 顾先生认出人后仍有联系方式，并未真的无从追查 | 只能先证明记录矛盾，尚不能单独证明私利动机；账册保留，调查不依赖丈夫再临柜台 |
| WM-E07 顾先生使用旁记 | 根据WM-E06两册相同日期查夹页，读到其收益记录与担忧镜子失效的旁记 | 他为保留能力主动压下线索；原先的“留”后来变了意思 | 不解释顾先生最终去向，也不把他写成生前已谋害母子；需要玩家主动对照，不能提前一次读完 |
| WM-E08 离家后的实据 | 第一章所得地址引出后续核查：联络人见证与当年的往来结算记录 | 丈夫恢复谋生、能够联络的时间，以及没有回去的事实 | 不以挣到多少钱直接判断全部动机；第一章不自动拥有这些材料 |
| WM-E09 丈夫对质 | 后续按证据询问离家、恢复生意、妻儿；记录承认、回避或反驳，供再次核查 | 经外部事实印证的承认，使其离家选择与自我开脱清楚 | 一句道歉不等于真相；证据不足或持续否认时为未决，可继续查，不用穷举对白强制认罪 |

“怀疑丈夫”与“确认丈夫”、“发现顾先生记录矛盾”与“确认他为私利隐瞒”各占不同知识阶段。身份链至少同时包含现实家庭关联和货郎独立来源的吻合；顾先生动机需WM-E07。未取得来源的结论不进入玩家口吻的总结。

顾先生旁记示意（新设计，非现有正文）：

> 人是寻得着的。只是这一问若问明白了，镜还照不照？

这句话须在联系方式矛盾已经成立后出现。先让玩家发现问题，再读出顾先生的选择。

### 缺失、迟到与退出

- 错过子夜货郎：持有或已记录铜镜特征者仍可查旧当存根，沿历史交易与联络人补齐身份链。失去的是当场反应和直接询问，不是调查资格。
- 当夜主动额度已用：被动异象照常；主动深入查看不可用，走现实材料。危险追看不作为票据调查的必经步骤。
- 从未窥镜：可查现实资料并作出判断，但不写成玩家已经亲自验证能力有用。
- 提前售镜：停止新镜中片段；保留已记录证据，现实调查仍可推进。无镜时不能远程对质女主人或触发她离去。
- 拒收且未取得材料／完全不查：继续七夜，收尾不主动揭晓丈夫或顾先生动机，不将未参与算作“知情利用”。
- 提前收铺、调查较晚：已开放资料跨夜保留；固定来访错过有替代调查入口。第七夜仍未完成的记录为未决，不免除正常游戏时间，不自动补齐关键证据。
- 查完后选择“继续使用”：是第一章态度，可在后续改变。正式完整分支只在具备事实和了结机会后成立。

## 7. 后续篇章与完整结局

后续不绑定具体夜次，不新增本轮未确认的经营、战斗或跨城系统。地点调查可以用有来源的材料和会面呈现。

### 7.1 节点与门槛

1. **沿地址找到丈夫。** WM-E05身份已证实，WM-E06提供渠道；先确认当前联络有效，不让丈夫为剧情便利无条件再来。
2. **核实离家经过。** WM-E08与他的口供对照，回答他什么时候有能力回来、为什么没有联系。将生意失败这一事实与后续主动逃避区分。
3. **面对事实。** 以WM-E03／04／08逐项对质，取得WM-E09中受证据支持的承认。其可能先否认、以曾留钱开脱，最后承认不敢回来；玩家不能靠重复点击无证据逼出真相。
4. **决定是否把答案带到她面前。** 持有有能力铜镜、无未决当夜危机，并取得上述核实材料，才可安排正式对质。明确行动是拿出旧当票、请他认清镜中人和说明当年的事，不把玩家一次窥镜或一句应声当成正式选择。
5. **让女主人作回应。** 丈夫在镜前承认妻儿与自己的选择，材料证明其说法；她可以不接受道歉，却结束等待。若他仍否认或证据不完整，不自动净化，留下继续调查、封存或利用的选择。

可以在掌握全部事实后主动不安排对质。没有镜子或始终找不到足够证据则是去向／调查未决，不伪装成完整结局。
