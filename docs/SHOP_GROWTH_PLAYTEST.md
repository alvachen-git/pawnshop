## 2. 一条建议的试玩路线

1. 打开“基础整修”快速入口，会进入完整设施场景。回柜台后，将鼠标移到画面最左侧稍停即可进入；也可点击左箭头或从铺务菜单进入 **修缮与查铺**。右边缘或右箭头返回；Esc先收起纸页，再返回。场景默认淡入淡出，没有切换方式开关。
2. 买一级鉴物台，检查现银少40银元、准备用掉1次；再买陈列柜，少60银元、准备达到2次。已买设施不能重复付钱。
3. 点击左侧陈列柜选择银簪，也可在库存展开货物操作后陈列。陈列柜内出现真实货物；撤下即移除。陈列不额外占准备次数。
4. 开铺正常营业。不是每夜都会有陈列买家；到店后仍可能被排队或其他待办耽误。普通工具检查中，原10分钟且用放大镜、灯、磁铁的动作现在是5分钟。原5分钟、来源核验、行家复核、铜镜操作不变。
5. 可提前关门，再点击中央旧账柜，依次做15、15、20分钟的三步核查。发现后才显示柜格与已取得材料。也可只查一步，次夜继续，或十夜都不查。
6. 想单独体验卖货，用“陈列买家”快速入口。买家先开价，可接受、拒绝或回一个更高的整数价；回价超过他愿意接受的数目，就此告辞。成交后看收款凭据与库存、账本。

两项设施也可分夜购买。新玩法不要求一次花完100银元。

## 3. 本批规则

- **设施**：第二夜起、开铺前准备结束前可买；每项占1次每日准备，当晚可用。设施投入单列，减少现银，不改变货物成本，不从交易毛利或经营净收益中重复扣除。
- **陈列**：一级1个位置，自有普通现货可放，在当货、鬼货、有未处理物品风险的货不可放。开铺前可换，营业时可撤；当夜不重新选目标、不重抽机会。撤下或另售会取消对应买家机会。未售且未撤的货跨夜持续陈列。
- **买家**：开铺锁定后按40%试验概率生成最多一位，19:00、20:00、21:00等概率到访，等90分钟。额外活人来客，与原当户、熟客、铜镜预约共用原接待顺序。可照客，不能向这位买家收购或放当。
- **价格**：开价为现有价值口径的90%/100%/110%，隐藏接受上限为110%/120%/130%，各档等概率；四舍五入、最低1银元。已证实来源按原15%规则计入，实际轮到柜前时固定。未复核折扇沿用20银元基数，不公开隐藏真值或最高价。
- **时间**：接受、回价各5分钟；拒绝不耗时。合法开始的报价先办完再处理买家等待到期；其他来客仍会超时。交易须在03:00前完成，无外出20分钟。
- **第十七柜**：第二夜起提前关门后主动查，三步免费、不占准备、不占每夜可选强事件额度。强制待办优先，时间不够不开始。恰好03:00查完，先记发现，再封铺处理风险。
- **资料**：旧柜目录、柜号矛盾、封闭柜格与私印观察保存在此页，免费复看。旧票只说明柜号与流转痕迹；不是铜镜旧票，不给第一阴账完整答案，不进入库存，不奖励现金。
- **保存**：整修、陈列变更、调查、成交及回价结果自动保存；无效或重复操作不追加记录、不写盘。写盘失败，钱、货、时间、客人、探索、准备额度与操作记录一起回滚。

## 4. 这次没有扩大的范围

保留原十夜、经营、铜镜、命灯与寝屋内容及资产。暂未增加二三级设施、专用高级工具、名声、原配组合陈列、后续阴账或自动卖货。长期“所有设施最终可建成”的方向不变，没有设施互斥。

经济试验显示这批设施是投资与效率选择：鉴物台能节约时间，陈列柜并不保证十夜内回本。40/60银元、40%概率及报价系数仍是待试玩调整的默认值。
