# 寝屋美术接入

采用负责人确认的「方案1 · 紧凑衣柜版」，对应 `artifacts/bedroom-design-v09/selected-01-compact-wardrobe-v2.png`。延续 ART04 不透明水粉方向：旧木、暗绿被褥、低饱和纸黄与局部暖灯。最左边是衣柜，实际房门在最右边。

## 本地试玩

在项目根目录双击 `试玩寝屋.cmd`。入口使用当前 `scenes/start.tscn` 的正式内容，自动走完首夜必要流程并停在寝屋，随后可以真实观察、查看旧信、就寝及继续游戏。首次准备约数秒。

试玩使用 `.artifacts/bedroom-review/appdata` 下的独立测试存档，不覆盖日常游戏档案。正式游戏的回房流程也已采用同一寝屋画面。

## 交互与状态

- 左侧书桌上、照片左边的油灯是命灯。鼠标移入或键盘聚焦即显示「命灯」；点击显示当前剧情灯况，移出隐藏提示。不会同时弹出第二层系统提示。
- 书桌旧信、照片仍接原有剧情内容。未摆照片时仅显示空相框，不能点击照片；摆放后显示姚曼卿的照片。
- 衣柜与墙镜可观察日常细节，不增加库存、交易或耗时机制。
- 床尾「就寝」进入原有确认，取消保留进度；就寝提示中的「放松入眠」完成过夜并直接进入次日，末夜保留结局账册。未决夜间事件仍须先处理。命灯熄灭时关闭观察及就寝，保留菜单。
- 右下角菜单调用正式游戏菜单。观察面板、菜单均可用 Esc 关闭，焦点返回当前场景控件。
- 房间全幅按原图比例显示，原柜台底栏在寝屋隐藏，离开后恢复。必要的夜次保留于左上标题下。

## 素材与实现

`assets/bedroom/room-normal.png` 与 `room-rest.png` 均为1672×941，由内置图像生成工具以定稿进行局部编辑。前者清除烘焙标题、床尾按钮、菜单按钮；后者仅提供空相框和熄灯补丁。`room_state.gdshader` 仅在相框、油灯范围采样状态图并柔化边缘，避免全图换图导致家具和笔触跳变。纠缠状态在原灯焰上略微转冷，死亡移除实际火焰。

标题、按钮、观察信息都是原生 Godot 控件。代码位于 `ui/room/private_room_view.gd`，宿主菜单及柜台显隐位于 `ui/counter/counter_screen.gd`。本次不修改运行规则、存档版本或剧情标记。
