# 开铺、封铺与回房响应 · 2026-09-15

## 原因与改动

十夜版在开铺准备完成、夜间结算、回房等节点自动保存。原先每次均从第一夜重新执行全部操作历史，后半程约需三百毫秒；与此同时，隐藏的鉴定、对话、交易、库存、账本页也在反复重建。

- v23校验器只保留一份已完整验证的历史前缀，连续保存只重放新增操作，最后仍逐字段核对完整状态。缓存独立复制，返回的状态及失败的校验不会污染它。
- 缓存核对完整历史前缀、实际内容配置、种子、人物尝试标识及此前终局档案。回退存档、分支、内容变化均重新校验。缓存不写入存档，旧版格式不变，原子写入、回读和失败回滚保留。
- 隐藏的五个经营面板延迟到打开时刷新；正在显示的面板仍随操作更新，父容器重新显示也会取得最新数据。

## 本机验证

以同一第8夜历史为例，不加载界面的回房动作由333ms降到约110ms。该数字不包含绘制，不能当作鼠标点击到画面完成的耗时。

实际游戏场景使用同一份历史、真实自动存档及按钮回调；从回调开始计到第一帧绘制完成：

| 操作 | 1280×720 | 1600×900 |
| --- | ---: | ---: |
| 开铺（包含结束准备的自动保存） | 251ms | 232ms |
| 关门 | 83ms | 85ms |
| 等到封铺 | 74ms | 82ms |
| 夜间结算 | 173ms | 220ms |
| 回房 | 206ms | 217ms |

以上是本机单次样本，1600×900运行期间还有回归测试，不能用于判断两种分辨率谁更快。测试使用隔离存档。首次校验、切换不同历史仍可能短暂停顿；本次没有改成后台异步保存，也没有削减校验或延后提交。

- `tests/investigation_replay_cache.gd`：100项通过，包括连续检查点与从头重放一致、历史与派生值篡改、返回状态隔离、内容变化失效、写盘失败回滚及重试。
- `tests/run_investigation.gd`：2362项通过。
- `tests/investigation_edges.gd`：58项通过。
- `tests/hidden_drawer_refresh.gd`：主目录与v23分别6项通过。
- `tests/checkpoint_performance_ui.gd`：两种分辨率分别11项通过。
- `tests/day_navigation_ui.gd`：32项通过。

## 发布整合

v23及上述优化已整合到正常源码目录，默认入口使用十夜版。校验器与专项测试均随源码交付，不再依赖独立试玩目录或补丁。原有v22及更早版本保存按各自内容读取。

测试使用隔离存档，正常存档未修改。重启v23即可使用，无须重新开局。
