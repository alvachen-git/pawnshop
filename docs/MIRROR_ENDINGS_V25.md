# v25 铜镜镜前旧事：试玩说明

2026-09-16，本地实现，尚未发布。基于 main `28f3a43` 的 v24，默认新游戏为独立 `mirror_ending_ten`，保留十夜经营、阿七、寝屋和所有既有系统。旧运行及存档不升级、不补结局或资源。

## 启动

在项目根目录运行 ` .\tools\play_v25.cmd `。本次隔离开发位于 `.tools/v25-playable`；用户现有根目录入口会转到此开发目录，避免运行旧副本。

```powershell
.\tools\play_v25.cmd
.\tools\play_v25.cmd -Stage ready
.\tools\play_v25.cmd -Stage willing
.\tools\play_v25.cmd -Stage refused -Wide
```

`new` 为正常新游戏；`ready` 可开始正式对质，`willing` 已完成愿意面对的第一段，`refused` 已完成拒绝面对的第一段。`-Wide` 使用1600×900，默认1280×720。缺少引擎时以 `-Godot "完整引擎路径"` 指定 Godot 4.6.1。脚本使用 ASCII，并只对本次子进程放行执行策略，兼容 Windows PowerShell 5.1。

三个快速入口使用 `.godot/test-appdata`、独立 `user://tests/v25_preview/` 存档，不读写玩家正常存档库。首次或相关源码更新后生成并验证测试进度，后续复用。`-Check` 用隔离目录启动检查后退出。正常新游戏仍沿用既有手动保存限制。

## 自然推进与暂缓

先取得现实调查材料，托人查访、主动拆阅回报，再完成丈夫的三段问答。持有仍有能力的铜镜、丈夫在柜前、没有赎当或其他强制事件与危机时，在对话或铜镜的「照看与处置」选择「把旧事带到镜前」。追看留下但尚未在寝屋应对的个人纠缠也须先处理。

当次会面可直接继续；离场后可再次花5分钟约下一夜20:00，等到21:30。每次预约的来访编号独立，人物仍是同一丈夫，没有新的怀表。8、9、10夜仅为示例；材料齐备即可办理。第十夜预约如约登记为第十一夜待办，试玩不会增加营业日或强行兑现。

正式对质分三段，各5分钟。开始、恢复和继续时必须足够在封铺及丈夫离场前完成全部剩余段落，否则不启动、不扣时。完成过的段落不重新收费。选择「暂且收起」保留进度与丈夫态度，允许经营和以后续谈；仅点击页面「收起」只隐藏页面，库存明亮惊叹号仍能直接返回。正在对质时，其他经营操作须先明确暂缓。

## 三条完整路线（含剧透）

| 路线 | 现场选择 | 结果 |
| --- | --- | --- |
| 当面认下 | 先说明镜中是谁，给丈夫自己开口的机会；把材料告诉她；请他亲口认下妻儿 | 她可以不原谅，却决定停止等待。丈夫活着，镜子成为普通旧物。 |
| 不再等他 | 直接揭镜，丈夫退缩；把材料告诉她；劝她不必再等他的承认 | 她的价值来自自己曾经的劳动、养育与求生，无须他许可。丈夫活着，镜子成为普通旧物。 |
| 以怨相留 | 丈夫拒绝后，在红影伸向他、说要将他拉进镜中的预警下，主动让她把苦还给他 | 丈夫当场死亡，女主人以怨留下，能力和覆红禁忌保留，获得铜镜怨气×1。 |

第一段确定的是丈夫是否愿意当面承担，之前承认逃避家庭的事实不会被改写；不随机、不因再约而改变。两种解脱前，她明确说离开后镜子只剩铜胎。报复用倒影、红影和声音交代，无血腥、遗体处理或亡魂回访。

三个完成结局互斥，本局不可改写。不查、暂缓、覆红、封存或卖镜都保持未决，不被判为第四种结局。

## 结局后的经营

- 解脱只停用关联的具体铜镜：不能辨生死、看旧事或危险追看，也不再有存放禁忌。收购成本、品相与估值保留，可按旧金属物件走回收商／适合行情的陆掌眼渠道。已取得材料与辨识结果保留，玩家命灯损伤不恢复。
- 怨恨铜镜继续每次5分钟照客、不限次数，正常照客不招祟；关铺前仍须覆红。v25将既有夜半收镜客的子夜收货窗口延续至第十夜，便于后期出售，价格倍率与单趟20分钟保持原值。
- 铜镜怨气是独立特殊资源，记录数量及结局来源，不能出售、兑换或消耗；卖镜不移除，不增加银元或随机伤害。
- 库存显示已了结／怨恨状态与不同镜面；见闻沿用分类、粗体标题和展开条目，只收录实际完成的材料、回答、对质和结局，不加入照客流水。

## 保存与边界

显式配置 `mirror_ending_version=1`，内容与存档25；自动位 `auto/mirror_ending_ten`，文件入口 `user://mirror_ending_ten/autosave_v25.json`。原有档案库及手动槽规则不变。

正式命令 `mirror_resolution_command` 纳入唯一最外层日志与重放缓存。结局落定时自动保存一次，能力状态、特定丈夫死亡、资源发放及通知一起提交，失败全部回滚。读面板不产生状态，重放不写盘或重复通知。报复死亡来源为 `mirror_revenge`，与次日换物赎当死亡分开，不进入玩家的《绝当录》。

本批不包含怨气用途、换物补救、新报复任务、阿七真相或第十一夜经营。验收结果和截图见 [v25验收记录](qa/v25/REPORT.md)。
