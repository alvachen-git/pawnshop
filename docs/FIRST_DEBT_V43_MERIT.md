## 规则

- 初始阴德0，范围-100～100；归还双镯加10，实际支付300银元和解加5，每局第一账仅一次。界面不显示数值，不改变经营或风险。
- 商量赔偿不扣钱、不结案。陈小满同意后出现实际付款选项；现银不足300时置灰、禁止点击，按钮直接显示原因。300银元可支付，消耗5分钟，款项、和解状态与阴德原子保存。
- 原物归还记“清”，现金和解记“和”。红黑账簿异动照常；玩家实际翻过支出、对应阴账后可看到一次回响。香炉反馈不自动授予这些知识。
- v42保留原奖励（两种结案均10），包括既有已结案存档。v41及更早不补奖。新规则需新游戏或本页v43测试入口，不修改旧档数据。
