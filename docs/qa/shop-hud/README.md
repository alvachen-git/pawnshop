## 迭代与结果

1. 首次交互检查发现菜单按钮被后绘制的底栏遮挡（P1）。将菜单节点放到底栏之后，保留原节点路径；复测菜单真实点击、Esc与焦点恢复通过。
2. 首次视觉检查发现招牌偏亮、底栏字和菜单图标偏小（P2）。降低招牌亮度、启用mipmaps，状态字体调整为20像素、菜单图标32像素，并加入细分隔线；以上全图与局部对照为修订后截图。
3. 最终对照去掉鼠标位于背景热区产生的悬停框，保持中性展示状态。无剩余P0/P1/P2问题。

可选P3：素材金属结构和参考图有细小差异；标准状态图标采用同一套线性图标，而参考图混用实心图形。实际界面保留统一笔画与可读性。
