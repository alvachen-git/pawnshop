# 报价期限修复合并验证

2026-09-13。基于 main c21d8ec 整理本次报价修复，保留已有命灯、夜市与客人常驻回复功能。

## 行为

- 正式收购或活当报价在客人期限前发起，先处理报价是否接受，再处理此次报价耗时内到期的客人。
- 接受则正常成交，仍耗5分钟；拒绝则先显示拒价，再接原有超时离店对白。
- 常驻回复栏明确显示拒价后离开的顺序；完整回复保留在详情中。
- 其他客人的等候、鉴货期限、封铺限制与价格门槛保持原规则。
- 已发生的旧档超时失败通过现有行动记录保留原顺序；新成交时刻要求报价在期限前开始。命灯完整操作重放同样兼容。

## 人工复测

在客人离店前剩5分钟提交足够高的报价，应扣款入库或生成当票；另一次接待提交低价，应先拒价再离开，现金与库存不变。两种情况均耗5分钟。查看结果不再次扣款或扣时。
