# 六位独立人物接入验收

## 实现

- 经确认的六张源图原样复制到 `assets/art04/customers/special/`；品红背景由游戏现有抠色材质处理。
- 以 customer_id 识别四位剧情客，以 person_id 区分许文衡、姜素云与同职业普通客人。
- 每人的高度、腰线分别对齐柜台；对话头像保持源图完整。
- 到期赎当和提前取赎均提供稳定人物身份，对话保留当票正文。
- 未修改排期、交易规则、故事文案、存档结构。发布分支基于 main 的 a99786b（含普通人物与标题页性能更新）。

## 验证

- `tests/special_customers_visual.gd`：1280×720、1600×900 的六人柜台与对话渲染，197 项检查通过。
- `tests/ordinary_customers_visual.gd`：152 项检查通过，普通职业模板和邻居仍正常显示。
- `tests/special_portrait_routes.gd`：4914 项检查通过，继承六条真实活当路线，包含提前取赎、延期、到期取赎、调包与保存校验。
- 六张游戏素材与已确认原图进行 SHA-256 比对；检查图片尺寸、导入资源和差异格式。
- 图像位置截图使用独立展示样例，不代表特定夜次的真实故事进度。实际回访逻辑另由流程测试验证。
