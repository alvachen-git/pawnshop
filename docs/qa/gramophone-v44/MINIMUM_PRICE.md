# 相机与留声机最低接受价 · v44

本轮用户确认：相机 120 银元、留声机 100 银元，收购与活当共用；人物筹款线更高时取更高值。

## 已实现

- v44 内容配置统一指定底价；v43 及更早入口不启用，不改写已成交当票或库存实际价值。
- 初始价格、货况谈价、军方照应牌及正式报价共同执行底价。即使说法全被相信、急售且低估行情，也不能突破。
- 正式成交再次核对底价，避免陈旧要价字段绕过限制。低于底价按正常拒价消耗耐心与轮次，不付款、不取得物品。
- 到底线后明确回应“最低 X 银元，再低便不出手了”；较高筹款线仍使用筹款对白。
- 物品实际价值和全部出售报价保持原规则，底价不保证转售保本。
- 修复普通留声机试玩强制所有说法通过、全额让价的问题；仅专项 partial/firm/exposed 保留指定反应。
