# 阿七对白误触铃铛修复

2026-09-16。聊天和理纸的事件成本均为 0 分钟；本次不修改事件或存档规则。

真实窗口复现：1280×720 下点击“理理纸”与铃铛重叠区域，旧界面执行了等客，game_minutes 从 0 变为 5，出现 n10_visit1，未写入阿七选择历史。聊天的确认按钮也可误触。原来的窗口测试只点按钮中心，未覆盖这些重叠区域。

原因：铃铛在 GUI 子节点顺序中位于对白之后，虽被较高 z_index 的对白遮住，仍优先接受点击；铃铛覆盖判断也遗漏了柜台对白。

修复：保持铃铛在经营控件之上，将阿七与主线对白排到铃铛之后，匹配显示与鼠标命中顺序；对白展开时禁用铃铛，收起后恢复。没有修改业务命令、时间成本、客流或存档。
