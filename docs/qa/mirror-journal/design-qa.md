# 铜镜物品记事排版 · 2026-09-15

final result: passed

## 问题与实现

原页面把旧档行动结果、镜中残影、查访回报与会面问答串在一个 Label 里，小标题与正文无区分，滚动后分类入口消失。

- 固定物品选择、照看/见闻切换及已取得的分类：旧当线索、镜中旧事、查访会面。
- 每条记录改为独立纸色区块：700 字重标题、取得夜次/来源、分隔线及正文；新记录排在前面，同一分类一次展开一条。
- 点击标题展开或收起；展开时将记录移到阅读区顶部，刷新保留分类、展开项与阅读位置。
- 增加铜镜、红布与旧册的淡墨装饰插图，完整等比显示。无新增人物、文字或剧情证据。
- 标题改为记录名，如“顾先生的夹页旁记”，正文仍取实际取得的原始结果。
- 未取得的类别不显示；回报未拆阅不展示来源材料，未问完不补回答；照客流水不进入记事。
- 危机仍强制回到照看与处置；其他物品和实际生成的绝当录保留原展示路径。
