# 阿七与柜台的空间、光照修正

2026-09-16，基于本地 v25 开发工作树；不改剧情与存档。

- 视觉目标：让孩子坐在木柜背后，保留暗处的神情，让柜沿材质和遮挡建立深度。
- 内容布局：沿用柜台原画、侧视人物和经营入口。头像退到原画柜面后沿，露少量衣领，桌沿作为真正前景覆盖身体。
- 交互与动态：保留既有点击／Esc／经营入口切换；人物明暗随原有开铺／入夜光照更新。不添加装饰性摇晃、入场惊吓或人物抢焦点。

旧版问题：矩形裁切落在木柜上表面中间（全画面y约0.522），而不是柜面后沿（y约0.474）；人物使用固定亮度，入夜后仍像独立照明的头像。

## 实现

- 移除人物下方的矩形硬裁切。完整侧视人物退到柜面后沿，露少量绿色衣领，让颈部与身体有连接。
- `PaintedCounterForeground` 直接复用 `counter_room.png` 的柜沿像素，沿原画木边轮廓建立前景遮挡。与背景共用同一光照材质和画面坐标，缩放和光照变化不产生接缝；遮挡限制在人物所在区域，不覆盖物品正文。
- `aqi_companion_light.gdshader` 降低皮肤饱和度、高光和曝光，入夜时使用更低环境光；衣领加深，右脸只保留少量明暗层次。由现有时段光照调用同步，不改时钟与剧情。
- 原位图未重绘，没有修改普通客人、初见搭桌立绘或任何存档数据。
