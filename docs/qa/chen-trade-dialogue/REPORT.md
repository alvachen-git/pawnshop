# 陈小满普通交易 → 凤镯对白验收

日期：2026-09-23。工作树 `.artifacts/first-debt`，分支 `codex/first-debt-v28`。本次仅本地修改，无推送、合并、发行包。

## 原因与修改

- 第二件物品来自 `FirstDebt.decorate` 在普通陈小满来访时额外启用的 `first_debt_relic`，不是库存复制。v29普通交易不再开启该层；交易结束后才显示凤镯，普通绣片图同时撤下。
- 对话混乱来自 `preserve_ticket_body`、最近任意 `fd_` 事件结果、认物旁白混拼。v29普通访客恢复原口供模型，资料反馈单独定向；包纸/工记进入现有旧当铺册页。
- 复用铜镜重逢的下方纸面、字体色、短段翻页和末页选项形式；陈家会谈不会一次堆叠资料、前次结果与多个事件正文。
- 交易后触发由真实 `visit_history` 推导，认物提交继续用原 `event_command`；原v29存档的前置认物允许历史回放，新调用不再允许抢在交易完成前。
- 5分钟托话跨过下一客到店时刻时，只保留陈小满回应的显示，真实队列照常更新，读完再显示新客。危机与死亡立即让出画面。

## 后续用户复测发现与补修

原验收漏掉“陈小满交易结束时已有下一客等候”，导致下一客先被显示、她随后再出现。上面的旧结论不能覆盖该边界。现已补充真实排队输入、队列连续性、防误操作、新客离开后不重现、原子保存与跨进程恢复，详见 [HANDOFF_FIX.md](HANDOFF_FIX.md)。当前真实窗口测试包含 `queued` 参数，两个尺寸各197项通过。
