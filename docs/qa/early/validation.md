# v18 熟客新约 · 提前取赎

本轮在本地熟客工作树内完成，未推送、未制作试玩包。默认新游戏进入v18；v17及更早存档继续按原内容还原，不把旧的绣片成交改写成赎回。

## 调整结果

姜素云中途来访时，若预定另筹款已经达到原票赎金，就持原票请求提前赎簪，不再带绣片出售。资金不足时，仍按原支线出售绣片。两种情况共用原先随机安排的中途席位，不额外增加顾客，也不固定到某夜。

玩家可以选择：

- 验票收赎，交还银簪：办理10分钟，收入原票赎金，交还原物，注销原票，到期不重复回访。不重算息费或减免固定费用。
- 仍按票上的日子来：不耗时、不收款，弹出“已约定回访”，保留原票和资金，到期照常赎回。

提前请求被错过、早关门或办理恰好结束于离场期限时，不结票、不入账；到期原主仍可按原约来赎。开票前与成交凭据中显示提前取赎需商议的铺规。已知往来和日结注明提前赎回或约定到期再来。

提前请求使用单独柜台指令，通过原有来访行动历史重放校验；不会重复收购抵押物、改变估值或生成绣片库存。原本金、赎金、票据ID及物品ID保持关联。

## 启动与复现

在项目主目录执行：

```powershell
& ./.tools/godot-4.6.1/Godot_v4.6.1-stable_win64_console.exe --path ./.artifacts/familiar-stories -- --seed=508
```

选择“新游戏”。508会让姜素云第3夜活当、第4夜中途来访，原到期日第6夜。放款25银元时赎金28、另筹30，会请求提前赎回；放款90时赎金99，则仍卖绣片。去掉末尾种子参数即可随机开局。

新自动档独立于v17：`user://familiar_early/autosave_v18.json`；六个手动槽仍共用，新局标为“鬼市当铺 · 熟客新约”。
