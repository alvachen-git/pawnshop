## 问题、修复和未验证项

- 首次干净导入时，项目级自定义字体在导入前被加载，产生字体加载 ERROR。已移除该提前加载设置；主界面与确认弹窗分别在 UI 主题层使用随包字体，重新导入验证，不忽略该错误。
- Noto Sans SC 可变字体默认字重是 100。Godot 未应用原始字符串 `wght`，现以 OpenType 轴 ID 设置 400，并通过 TextServer 实际坐标断言验证。未裁剪、未修改字体二进制，原始 OFL 随包保留。
- 早期测试构建入口的空参数数组导致 PowerShell Count 错误，已修正并完成全套复验；初次失败日志保留，不计入通过结果。
- 官方大模板传输缓慢/超时，使用官方 URL 范围请求续传；不关闭 TLS 验证、不修改系统代理。最终仅允许官方完整 SHA-512 校验通过的归档进入构建。
- EXE 录帧时 MovieWriter 报告 C 盘仅余约 4.3 GiB；三帧录制完成、图片有效，原始警告保留。已删除约 2.63 GB 本任务已合并的下载分段/重复副本，保留校验过的完整模板。该空间警告不等于脚本或游戏失败，也没有被从日志删去。
- 未代码签名，SmartScreen/安全软件拦截情况待实际环境反馈；不要求关闭安全防护。
- 未验证 Windows 10、7/8、ARM64、其他 PC/GPU、125%/150% DPI 矩阵、无相关工具安装的全新机器。只能报告本机结果，不标为已支持。
- 本轮不包含正式美术/音效、49 夜、玩法扩展、完整体验时长验收或公开发布。
