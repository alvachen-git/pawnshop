
这是已完成自鉴、尚未谈价的普通客人场景。进入“商量价钱”，选择“这不是真迹，价钱得再降些。”，随后自己填写正式收购价。

| 参数 | 场景 |
| --- | --- |
| `-Stage normal` 或不加参数 | 正常十夜，从标题页新游戏开始 |
| `-Stage fan` | 尚未落笔的折扇，体验拖动、圈点、免费草稿和确认落笔 |

三个议价场景已完成“私下认定为真迹”，以方便测试私下判断与对客说法的独立性。使用自然生成的固定种子0／1／40，通过正常行动进入第五夜；没有改写物品真假。`fan`场景仍未自鉴。专项入口每次从固定起点开始，可在游戏中读取自己后来保存的进度。

首次启动会检查工程并生成验证过的试玩资料，需稍候。启动器各场景分别使用 `.godot/play-data/unified-v28-场景名`，互不覆盖，也不覆盖旧版目录。出错日志在 `.godot/qa/appraisal/`。

## 本批怎么玩

1. 在鉴物台比对图录与折扇，自由改选“相合／有异／看不准”。草稿免费，确认落笔才一次扣10分钟。
2. 正式判断名称为“顾砚生真迹／临摹画／假画”，仍由玩家决定；实际真假不受玩家选择影响。
3. 回到交易页，在“商量价钱”里另选对客说法。即使私下认作真迹，也可以声称不是真迹压价；不会改写鉴定或卖货估值。
4. 谈这句话耗5分钟、一次议价机会，与原“这东西没你说的那么值钱”共用一次试探。仍需另报正式收购价，达到客人的底价才成交。
5. 识货由独立配置决定：旧书铺先生懂行，富户管事和失业账房不懂行。懂行者拒绝并减少一点耐心；其他人按是否急用钱让价。反应不读取真假。
6. 只对普通折扇的买断收购生效。活当照原有金额；特殊来客、预约、陈列买家没有此入口。必须能在客人离开与03:00之前谈完，恰好到期限也不能开始。
7. 收货后可请行家复核。私下判真且复核为真，鉴定名声+1；私下判真但复核为临摹画或假画，−2；私下判为其他类别不增减。直接送检不加名声，同一件不重复结算。

## 开发验收用说明：隐藏商誉

只有“实际真迹＋判假压价得到让价＋买断成交价低于压价前要价”才记一笔−2。误判与故意说假一视同仁。假货、临摹、拒绝让价、未成交、活当或原价成交均不扣。复核不会再扣。

本批只写隐藏事件账；玩家界面、结果、凭据不显示扣分，不改变客流或阵营关系。后续统一商誉需要按**所属运行与事件ID**去重；存档分支重放不重新生成这笔事件。
