## 启动

在任意PowerShell目录运行：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\play-unified.cmd" -Stage watch -WatchCase guide -Wide
```

进入铺内，点击上排第二柜，打开《名表鉴定指南》。翻页及试听免费，研习占1次准备、不收费，掌握后不可重复扣准备。第二柜与原第四柜交换知识摆放；旧存档不交换。

指南仅有“听走时”和“看机芯”两页，不再列出估价答案。机芯页只展示原配参考图，在夹板／轮系、机芯座／固定处标出观察重点；实物的换芯和仿制仍在这些结构上呈现差异，须由玩家比对。

三段样音均为8秒，开头相同。正常持续均匀滴答；竖放停顿在两处断几拍后恢复；中途停走约在一半处停下，剩余时间安静。页面显示当前试听、进度和听完状态，也可开启节拍辅助。停顿只提供运转线索，不证明名表身份。

查验与交易试玩：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\play-unified.cmd" -Stage watch -WatchCase fault -Wide
```

点桌上怀表 → 鉴定 → 器材鉴定，先上弦，再分别平放、竖放完整试听。听完可直接记录运转判断，无需在时间条上标记；也可开盖点击机芯细节，右键放大。在“记下判断”内选择已掌握的结论，再回柜台拿新证据谈价；不必等三类判断全部齐备。已用于谈价的判断不能改写。

“确认落笔”不要求听完两种姿态或查齐机芯细节，可以保留暂难定论。保存成功即关闭手记、验表台与鉴定抽屉，返回柜台；落笔后判断不可改写。证据是否充分在举证时另行核对，落笔不会自动补齐证据或确认真假。保存失败时保留手记并显示原因。

`-WatchCase`可选：

| 参数 | 隔离预置 |
| --- | --- |
| guide | 开铺前，二柜学习与试听 |
| natural | 按种子生成当前怀表的认识、声音与要价 |
| bargain | 完整真表被当作普通仿表低卖 |
| overpriced | 仿表被客人当作完整名表报价 |
| urgent | 客人急用钱而让价 |
| bluff | 无凭贬价会被接受 |
| spotted | 无凭贬价会被识破 |
| fault | 原配真表有姿态停顿 |

这些均是明确标注的测试预置，进度不写正式存档；预置参数不能用于正常新局修改货况。正式新局去掉全部参数。其余高档货仍可使用原`-Stage wealthy`与`-Item`选择。

新版柜台的十种高档货复用普通物品鉴定面板：物品图、证据估值区间、你的判断、已见线索与检查按钮。怀表未检查时为25–500银元，包含可能的外伤与运转故障；外观查明后按外观比例收窄。真假、未查明故障及客人心理价不参与这份区间，玩家草稿也不作为自动验真的依据。器材内的检查玩法及真实货值不变。

## 价格与证据

固定实际货值＝身份与修配基础价（500／350／100）×外观比例（100%／80%／50%）×运转比例（100%／80%／50%），最后四舍五入，最低1。生成后查验、错判、谈价和读档均不改货值。本次不做维修。

运转按70%连续、20%姿态停顿、10%停走独立生成；未上足弦另算，不作为永久故障。指南和实物共享合成节拍算法，实物停顿位置固定但不同物件可不同。样音是游戏教学声音，不是品牌实表录音。

客人另有识货程度、真假认识、行情倍率和急迫程度。开价与底价由心理价生成；低估不能使实物变便宜，高估也不能把仿表变贵。厂主活当最低需163银元，买断不套用此资金线。活当参考50%，买断70%。

外观、身份与修配、运转三类证据分别承认。举证5分钟、1轮，混合举证中正确部分有效，错误部分扣一次原有耐心；同一证据不重复使用，不通过反复改判断试答案。

无凭贬价另列选项，5分钟、1轮，每次来访一次。懂行／略懂／不识货识破概率80%／45%／15%；双方已确认的事实反驳该说法时必定识破。接受则现要价与底价各让15%，最低筹款线仍有效。虚假说法被识破商誉−2，遵守每日负奖励上限；未识破不暗扣商誉。正常低价成交、低报价失败不扣商誉，高价奖励与累计十笔奖励保留。

所有出售渠道采用固定实际货值及既有买家规则。出售后记实际收入、进货成本与盈亏；未绝当抵押物不能出售。三夜当期、本金加10%费用及每票赎回结果不变。
