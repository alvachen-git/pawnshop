# 固定柜台低保真美术骨架

依据 `设计/鬼市当铺_美术设计规范_V0.2.docx`、`设计/鬼市当铺_UI线框规范_V0.1.docx`、用户布局草图与 P0 资产任务分包表。概念图只提供方向，未将其文字或图像直接用作游戏成品。

## 运行与查看

在 Godot 中运行 `scenes/main.tscn`。原有开铺、鉴定、询问、收购、活当、库存、账本和夜间流程继续使用各自 Presenter。

专门验收美术时，在编辑器打开 `scenes/counter_review.tscn` 并按 F6。它继承同一个主场景，只锁定 M6 内容夹具和独立测试存档，避免同时开发的新经营内容影响布局对照；不是第二套 UI。默认主场景仍使用生产 Manifest。

- 点击「收起 · Esc」或按 Esc，查看完整柜台。
- 「营业、鉴定、对话、交易、库存、账本、更多」为七个常驻入口。
- 「更多」包含铺中记事、鬼货与绝当录、夜间结算。
- 调试构建内，点击「更多 → 美术预览」依次轮换正常营业、深夜异常、禁时鬼市、随游戏。每次选择后收起菜单；右上角明确标注预览状态。发布构建隐藏这个入口。
- 预览只修改表现层，不修改时间、阶段、现金、物品、选择历史或保存数据。禁时鬼市目前只有美术骨架，不代表已经实现鬼市玩法。

## 布局与色彩

采用现有 1280×720 逻辑画布，通过 Godot `canvas_items` 等比适配 16:9 窗口；1600×900 为主要美术验收尺寸。

| 区域 | 全画面位置 | 用途 |
| --- | --- | --- |
| 顾客与街景 | 上方 0–47.5% | 固定门框、街景、半身角色、身份纸签 |
| 物品与柜台 | 约 50–82% | 验货垫、物品占位、描述、香与命灯 |
| 功能入口 | 约 83–90% | 七个文字按钮，保持清楚的鼠标与键盘焦点 |
| 底栏 | 最下方 9.6% | 时辰、夜次、现银、债务、在当票据、香火、阶段 |
| 功能抽屉 | 右侧约 39% 宽 | 按需叠加；不改变柜台位置，不覆盖底栏与导航 |

旧木 `#5E4635`、纸 `#D8C7A2`、铜绿 `#60756A`、印泥红 `#8D2A24`、异常冷光 `#AFC4C9`。正文用清晰黑墨，按钮区分默认、悬停、按下、禁用和键盘焦点；磨损、网点只画在场景上，不覆盖文字。字体优先使用系统中文黑体，正式跨平台分发前仍需确定可打包字体与授权。

## 三态与规则边界

| 视觉态 | 保持不动 | 改变 |
| --- | --- | --- |
| 正常营业 | 门框、街景轮廓、柜台、货架、顾客和物品位置 | 暖灯、低饱和褐木、稳定香烟与暖色命灯 |
| 深夜异常 | 同一空间与 UI 锚点 | 街景局部变暗；预览增加一处横走的香烟 |
| 禁时鬼市 | 同一空间与 UI 锚点 | 冷青街景、原位置红灯、不合理的灯影与冷白命灯；不增加鬼脸或黑气 |

实际游玩从 23:00 或关门后压暗空间；香烟倒伏来自已有入侵记录，命灯偏斜来自已有危机、纠缠和相应后果。单纯时间变晚不会伪造违规反馈。底栏保持真实运行数据，不随美术预览伪造日期、现金或危险值。

债务栏接入工作区新增的本金／息费短款数据；未启用债务规则的旧夹具显示「—」。底栏的「在当票据」只统计有效当票，不把历史票数当作当前持有量。

## 文件与替换挂点

| 文件 / 挂点 | 当前交付 | 后续正式资源 |
| --- | --- | --- |
| `scenes/main.tscn` | 柜台、顾客纸签、物品说明、导航、底栏、抽屉 | 保留区域锚点 |

| 同文件 / `_parcel` | 通用货包，仅验证物体体量 | D/E 系列物品与铜镜检视图，按 visual_asset_id 接入 |

首批骨架共用货包和半身占位。第二批 ART02 已为青花碗、黄铜烛台、铜镜接入独立检视图，并接入四种顾客模板；原来的通用绘制保留为未映射资源的回退。正背面不泄露隐藏品相，局部细节须取证后才能查看。详见 `docs/ART02_ITEM_CUSTOMER_SKELETON.md`。正式精绘与复杂特效仍未纳入交付。
