# 陆掌眼登门 · v43

基于 v42 瓷器整合版，保留原有夜次和交易机制。

- 第一夜隐藏陆掌眼来信、买家和口信历史，直接发起交货也不能绕过介绍。
- 第二夜开铺前，孙大元原有登门结束后，陆掌眼来到柜前。三段对话依次介绍与顾掌柜的旧交、替商号采办的贸易身份、按当前需求收货与来信方式。
- 陆掌眼登门复用已有 RPG 对话组件：场景与立绘保留，底部短句翻页，独立回应选项，旁白与人物分开署名；回应和告别也在同一对话框内展示，可收起重开。
- 收下名帖并告别后解锁来信。开铺前即可阅读需求，正式交货仍须开铺、安顿店内来客并往返20分钟。
- 对话不扣钱、不推进时间、不占普通顾客名额；逐段自动保存，保存失败回滚，读档不重复完成的对白。
- 背景收音机默认关闭；鉴定等操作音效沿用原设置。
- 老年陆掌眼立绘用于本版介绍与后续龙镯登门；v42 保留原立绘。
