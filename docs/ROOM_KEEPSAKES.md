# 寝屋照片与私人信件

基线 main：`e819363`，独立分支 `codex/room-keepsakes`。本批为现有命灯 v22 的兼容增量，不建立新运行，不更换自动位置，也不要求重新开局。

## 玩家操作

首夜安顿完成后，在正常寝屋点击桌上照片，可观察、收进抽屉或放回原处。未摆出的照片从书桌的私人物件入口查看；第一次摆放显示“摆到桌上”，从抽屉取出显示“摆回桌上”。书桌也提供“私人信件”列表，目前只登记已经收好的顾敬堂来信。未获得时不显示标题或正文，不再出现无来源的备用信。

信件正文滚动阅读，固定“放回抽屉”返回列表；Esc 返回上一层，列表关闭时回到书桌热点。Tab 焦点限制在面板内，Page Up / Page Down / Home / End 支持正文滚动。照片、列表和正文共用面板，遮罩拦截对床及房间的点击。就寝、切换场景或读档会关闭私人面板。

这些操作不耗时，不推进剧情、危机和过夜结算，不改变现金、人物关系或命灯。正常命灯反馈、黑窗、局部暖光及镜面保持现有表现。更早运行保留原有单封信与照片观察功能。

## 服务和兼容

`RoomKeepsakes` 统一提供可用性、照片位置及已获信件的读模型；信件登记项使用稳定 ID、标题、正文键及获得标记。本批只有 `gu_jingtang`，不新增剧情或已读统计。

`RunSession.execute("photo_place")` 和 `execute("photo_store")` 先校验阶段和当前位置，拒绝重复动作而不追加操作记录；有效动作仅更新照片状态，并通过既有命灯事务保存。写入失败回滚完整状态与操作记录，界面保留照片和重试按钮。

命灯状态新增 `room_photo_position`：空字符串沿用不可变的首夜选择，`desk` 表示桌上，`drawer` 表示抽屉。仅命灯运行序列化该字段。首夜 `INTRO_MANQING_PHOTO_PLACED` 标记始终保留，不用它记录后续摆放。

旧 v22 存档缺少字段且没有照片命令时，校验时补充空字符串；加载不立即重写源文件。出现照片命令的存档必须保留字段并通过真实命令重放，删除字段、改变位置或错误类型均不能绕过校验。保留自动 `auto/life_lamp_seven`、v22 版本及六个共享手动位置。

## 本地试玩

在本工作树根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\preview_room_keepsakes.ps1
```

默认自动走过首夜并停在可操作寝屋；点击照片和书桌即可测试。不会演示自动故障注入。可加 `-Width 1280`，默认 1600×900；加 `-Play` 从完整游戏标题开始。脚本自动寻找祖先目录中的 Godot 4.6.1，也支持 `-GodotPath`。

试玩使用 `.artifacts/keepsakes-preview/user` 隔离存档，不影响现有个人进度。正式游戏读取原有命灯存档时，照片按原选择显示；新功能无需重新开局。
