# 客户回复 · 2026-09-11

负责人试玩后确认：移除普通成交、拒价离场、超时离场、拒收后快速出现又消失的结果页。沿用下方结果记录，改为简短客户回复，不再播放交货→盖章→跳款的限时步骤。

## 五类回复

| 情况 | 例句 |
| --- | --- |
| 满意成交 | 掌柜爽快，就照这个价。 |
| 不甘心成交 | 唉，再低也舍不得了……就这么着吧。 |
| 拒绝成交离开 | 这价钱谈不拢，东西我带走了。 |
| 时间到了离开 | 时候不早了，我还有事，先走一步。 |
| 被拒收离开 | 既然掌柜不收，我再去别家问问。 |

- 回复在原结果条目第一行署名显示，第二行保留结果、物品与详情入口，不冒充下一位客人的对白。
- 不设自动消失计时；直到下一条结果、主动收起、读档、新局或返回标题才更新或清除。必要剧情或凭据复查期间暂时隐藏，之后可恢复。
- 成交满意度只使用操作前公开要价和已经显示的不耐烦态度；收购用收购要价，活当用活当要款。低于本次要价成交或已有不耐烦态度时使用不甘心回复；不读取隐藏底价、真实品相，不改变成交规则。
- 报价不成但仍在谈价时，保留当前页实际回应，不误写客人已经离开。耗尽谈价机会才使用拒绝成交离开的回复。
- 排队者离场不打断当前接待；若同一操作同时成交和排队超时，保留成交回复，排队离场补充在结果提示中。
- 特殊提前取赎仍保留原剧情缘由；赎回、续当、出售、调查费用直接保留对应业务结果，不硬套收购物品的说辞。
- 真实资金与物品状态立即更新，不延迟显示、不重复记账。普通结果不阻断输入、不播放收货章声音。主交易按钮随真实接待状态刷新，旧来访 ID 不可重复成交。
- 首单手动盖章、铜镜规矩和必要夜间选择不变。活当记录仍明确留铺保管与到期夜次；详细凭据继续主动打开。
