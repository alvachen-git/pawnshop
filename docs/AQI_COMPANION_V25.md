## 剧情顺序

| 时点 | 发生的事 |
| --- | --- |
| 第二夜／第五夜寝屋 | 原夹袄、旧信夹纸主动观察，至第七夜结束保留。可全部错过；复看免费，不重复记入 |
| 第七夜准备 | 无阿七人物预告或新提示 |
| 第七夜开铺后 | 普通柜台初见，问名、帮助修风车或婉拒。看过夹纸才可提问；完成后带走风车，恢复原接待 |
| 第七夜核账、危机后 | 独立翻出“尚欠七账”，可查旧铺草图；随后回房 |
| 第八夜开铺后 | 按是否帮忙回应风车，再询问能否留下。两种许可有不同短回应；婉拒当日离开 |
| 第九／十夜开铺后 | 已获许可直接到左侧陪伴，不自动弹长对白。之前一直婉拒则简短再问 |
| 第八／九／十夜空闲 | 每日一段新闲聊、一段小互动；第九夜可选折小船或小鸟，复看显示原选择的结果 |
| 22:00或提前关铺 | 陪伴退出，不打断跨时动作、不占用告别／成交反馈；主动请走后当天不再返回 |
| 第十夜核账、危机后 | 发现陈阿福旧票，可对照旧账或先收好。核对后另有短页展示日期疑点，随后正常回房、就寝、结束；无第十一夜 |

第二次来访按首访选择说“这回转得可好了。走来的时候，我都没使劲吹。”或“我后来自己拨了拨，能转一点了。”她想留下看生意，获准后指向左侧：“那我坐这里。有人来了，我就不插嘴。”第一次婉拒不写成帮助；陪伴婉拒不责怪玩家，也不影响阴账。

聊天、理纸、查看与修风车均不耗游戏时间、钱或材料，没有好感数值和经营收益。中央客人、赎当人、会面或风险待办存在时，阿七不插话；点击只短暂显示“先招呼客人，等会儿再聊”。空闲时点击左侧人物可选「聊两句」「一起理理纸」「今天先回去吧」。Esc、菜单和经营入口均能收起日常对白。

## 旧票的已知边界

对应 GDD《早绝的金镯》，本批仅做旧票引子，不提前完成案件或清账。

首次发现显示陈阿福、龙凤金镯一对、当金十八银元，以及“五夜”附近刮毛、墨重的痕迹。选择「对照旧账」后才确认原“七”字残笔与第五夜出货记录，形成是否真正逾期的疑问。选择「先收好旧票」不补写核对结果。

账本「旧事」只展示已发现内容；未发现时仅提示旧账未翻查。阴账、已取出的草图、旧票及核对结果均从事件历史读取。阿七不提供证物，不讲解案件；不生成可售金镯，不增加财务债务，不开放赔偿、归还或转债，不揭示身份、父女关系或续契动机。

## 结构与兼容

- 新 manifest `data/aqi_companion_manifest.json`；run／事件在 `data/aqi_companion/`。v24 manifest、run、阿七事件原文件未修改。
- 开铺初见与再访属于营业阶段的必需事件，优先展示且零耗时；没有替换、删除或新增普通来客位。七夜阴账、十夜旧票保留 `shop_resolution`，危机响应优先。
- `AqiCompanion` 提供应用层只读模型。陪伴由许可、落座、当日婉拒／离开历史的已知标记、夜次、阶段和时钟推导。每日选择仍经过 `RunSession.event_command`，主动事件不加入全局待办。
- View只保留打开哪页的临时界面状态。首次选择原子保存；重复请求失败且状态不变，复看直接显示历史回应。写盘失败恢复完整动作记录及发现状态，并显示重试错误。
- 开铺和营业剧情自动检查点使用现有完整动作回放。自动位 `auto/aqi_companion_ten`，备用单档路径 `user://aqi_companion_ten/autosave_v25.json`；六个手动槽、现有档案库共用。营业中手动保存仍不可用。
- 旧局照原内容回放；默认标题新开恢复v25。不修改前十夜客流、经济、镜子、命灯、读档政策或丈夫预约算法。
