## 已实现

- 第四天结识虚构管事沈伯钧，沿用柜台人物与底部分页对白。《往来簿》按军阀、青帮分别存储来信、旧事和互动；玩家界面不显示关系或商誉分数。
- 第五天首次照应钱，此后按实际登门日加8夜；50～100银元费用生成时锁定。支付改善关系，拒绝恶化关系且不记欠账。同夜其他势力强制事件或实际关键会面会令收费顺延。
- 低关系营业夜开铺时判定砸店；严格低于−10、25%概率，拒交当夜豁免，之后五个完整夜次免于再次砸店。结算商誉损失和至多两件不同普通物品报废。
- 自有物与普通在当物均可能受损；关键剧情物、熟客专属物与陈设排除。报废保留记录并关闭出售、交货、正常赎当入口。
- 当户回来时免本金息费核销，同一当户在同次砸店中的损失合并交涉；无人在到期前回来则直接损毁结案，不生成投诉或转当收入。
- 三份固定货源：清楚来源的钢笔、姓名被磨的怀表、权属未转让的绣片。购买前有线索，允许核查；普通拒买无处罚。两份争议货均可进入退货、补偿、请青帮介入或延期交涉。
- 10银元付费打听，下一夜收信；一项未完成委托，同物不重复收费，卖掉物品仍可收信。20银元、1点开铺前行动的备礼赔话，间隔两个完整夜次，负关系可用。
- 费用、关系、砸店、调查与追索全部通过业务命令和存档记录结算，页面查看不重抽。没有制作讨债功能。

首轮规则集中于 `data/qingbang/rules.json`。额外采用的试玩默认值：空闲夜25%货源邀约，两次邀约之间隔两个完整夜次；柜前核查货源2银元、10分钟；公开追索沿用退货协调、半价补偿和关系足够后势力介入的处理方式。
