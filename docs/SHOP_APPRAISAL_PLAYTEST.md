## 启动

在项目根目录执行：

```powershell
.\play-v27.cmd
```

正常开局包含最新铜镜与阿七剧情、设施成长和扇画自鉴。同一局仍以十夜为边界。已有游戏存档不被替换，正常试玩自动保存到此独立工程的 `.godot/play-data/unified-normal`。

快速体验两处比对：

```powershell
.\play-v27.cmd -Stage fan
```

直接体验改造与研习：

```powershell
.\play-v27.cmd -Stage upgrade
```

添加 `-Wide` 使用1600×900。专项使用独立存档目录，每次进入重新建立该场景；不把已解锁工具或现金写入正常开局。首次准备专项会验证资料，需稍候。启动器使用现有 Godot 4.6.1，也可通过 `-GodotPath` 指定。

## 正常获得能力的过程

1. 第二夜起，开铺前整修一级鉴物台，40银元、一次准备。
2. 提前关门，在旧账柜“整理旧账”，15分钟，免费。
3. 循目录找工具册，10分钟，免费；取得旧工具册和《顾砚生扇画摹存》。这一支不要求先查完第十七柜，也不解释旧票的真相。
4. 次日准备时，委托二级台改造，80银元、一次准备，两夜后开铺前自动完成。期间一级功能照常使用。
5. 图录研习不收费，占一次准备；可在等待施工时学习。
6. 二级台完工后添置扇画工具，30银元、一次准备。当晚可用。

台体、工具、知识分别记录。所有准备共用每日两次，工具与改造支出计入设施投入。最早可以在第五夜具备全套能力；共投入150银元（含一级台），需要留出买货与每日息费的周转金。

## 如何比对

柜前折扇从“鉴定→扇画比对”进入；自有折扇从库存进入。

- 左侧图录、右侧折扇均可拖动。先点图录局部，再点扇面对应位置；底部并排放大所选画面，右键或“放大”可进一步细看。
- 只比对**笔法转折、题款与旧折**两处，分别记为相合／有异／看不准。草稿自动保存，可以免费重选圈点与看法；只设一个“清空草稿”按钮，同时清空两处。只想改一处时，点对应手记直接重选。
- 两处完成后点击“落笔”，查看初步结论，自行选择顾砚生真作、同时期临摹或后添名款。点“确认落笔 · 10分钟”才正式提交并扣时，返回修改免费。不公布对错，不自动获得行家认证。
- 看图录、圈点、重选、放大与复看免费。拿不准可先合上，重新打开仍保留草稿；每件扇只正式落笔一次。旧存档已经支付检查时间的未完成鉴定可抵扣本次10分钟，不重复收费、不退款。
- 收购前后均可比对；只允许柜前正在接待的待收折扇或自有现货，不能拿其他当户的抵押物练手。
- 落笔前检查能否在客人期限及03:00前完成；不足或恰好到期限则不开始、不扣时，保留草稿。不许验货的客人在实际鉴定时仍会收物离开，已用检查时间计入，不取得正式结论。其他客人的等待随有效落笔照常推进。

## 自鉴、名声与价格

用户确认：玩家可以自己判断，但鉴定名声低时对价值影响较小；鉴定名声先通过行家复核积累。它与普通商誉分开。

本批模型：

`自鉴计价基数 = 原未复核基数 + 四舍五入((玩家所判类别基数 - 原未复核基数) × 认可权重)`

- 折扇原未复核基数为20；玩家所判类别按现有75／35／20取值，**不使用隐藏真值替玩家改判断**。
- 鉴定名声初始0；权重 `20% + 名声×5%`，限制在0%—60%。玩家界面只描述认可程度，不显示隐藏分数或真值。
- 初学者判真作时计价基数31，判临摹23，判后添款20；是否判断正确，不会在这一刻自动公布。
- 认可权重在该件落笔时固定，后续名声变化不重写旧货签或已给出的买家报价。
- 收货后仍可请行家，沿用6银元、20分钟。复核符合原判断，鉴定名声+1；不合−2，限制−4至8。每件只结算一次。没有先自鉴的直接送检不增加名声。
- 行家复核后，沿用现有专业鉴定价格口径，不再采用自鉴折算。原渠道系数、来源15%及陈列买家实际接待时锁价保持。

这是有限的“买家认可自鉴”试验，尚无买家日后追索、退货或售后验证系统。不能据此声称全部经营策略已平衡；持续虚报真作的激励与以后买家反馈需要进一步试玩讨论。

## 体验时重点观察

- 两处证据是否足够理解，是否有机械背答案的感觉。
- 150银元投入是否明显挤压买货；两夜工期是否还有可做的经营选择。
- 低名声时自鉴的小幅认价，是否仍让收购前的判断有价值。
- 请行家验证并积累眼力名声，是否比直接选最高品类更有吸引力。
