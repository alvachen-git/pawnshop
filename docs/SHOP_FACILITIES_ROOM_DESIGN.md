# 当铺设施场景设计 V0.3

日期：2026-09-16。状态：**已在隔离副本接入一级经营玩法与铺内场景；初始、一级、二级、三级外观可独立预览。**

用户确认本批范围：“先接入现有一级玩法，四级外观提供独立预览，再定高级规则”。这里“四级外观”指初始加一至三级，共四阶段。中央旧账柜也随预览等级明显翻新；实际经营中其修缮取得方式尚未定稿，仍保持原外观，免费查账不代替付费升级。

**标识修订：** 按用户截图反馈，场景名称与设施悬停名改为无底框的暖白题字，去掉整柜矩形焦点框；“回柜台”文字牌改为独立木铜箭头，悬停或聚焦提亮。沿用原点击、边缘停留和Esc行为。下面早期交互稿中的“小纸签／返回文字”以此为准；具体对照见最新视觉复核。

**箭头微调：** 两侧入口均为小箭头：进入铺内向左，回柜台向右。箭头实形约48×14像素，两种分辨率保持相同大小；使用稍亮的浅铜色与96%不透明度，避免融入深木背景，仅轻微悬停提亮，不漂移。按钮的隐形点击范围保留。

**规则边界：** 旧账柜外观成长得到用户明确要求；取得外观等级的方式、费用、收益和工期尚未确定。免费“整理旧账”仍是调查行动，不能因此被改为收费门槛。柜体外观与探索进度分开记录和表现，修好柜门不自动发现目录、柜号矛盾或暗格。已发现的暗格也不能因翻新消失。

二三级图中工具、陈列货物与资料为已取得时的展示例子；购入台体不自动赠送这些内容。概念图柜门细分与编号仍有生成误差，正式资源必须固定十六柜结构并由引擎绘制正确编号，不能直接当作最终解谜底图。

## 2. 固定空间关系

玩家位于柜台内侧，向左进入完整设施区。两处场景固定构图，以淡入淡出衔接；右侧保留柜台连接处，空间尺度和眼平高度与当前柜台一致。

| 区域 | 位置及职责 | 构图要求 |
| --- | --- | --- |
| 陈列柜 | 左侧窗下，选择、撤下与查看自有陈列货物 | 保留足够面积看清单件货物，低反光玻璃，陈列物独立绘制 |
| 旧账柜与柜墙 | 中央，整理旧账、核对柜号、检查夹板、复看材料 | 中部账册可点击；其他柜格随调查提供对应热点 |
| 鉴物台 | 右侧前景，查看台体状态、整修与已有工具 | 台面、台灯、工具位置清楚；整修效果与柜墙独立 |
| 返回柜台 | 最右侧，柜台接缝和方向提示 | 始终保留明确去向，不被操作纸页覆盖 |

室内不摆一排脱离场景的设施卡片。默认主要看房间；靠近物件出现名字，点击才出现操作。

## 3. 边缘进入与导航

以下时间、尺寸是交互初值，待真实双分辨率操作调整。

1. 柜台左侧保留约32像素边缘区域（1600×900基准），以小型浅铜色左箭头指引进入。
2. 停留约350毫秒后启动约180毫秒的淡入淡出。离开边缘即取消尚未开始的触发；点击箭头可直接进入。
3. 设施区右侧以同款右箭头返回。切换完成后必须先离开边缘、再次进入才可触发，避免连续往返。
4. 过渡时冻结第二次导航输入，但不创建经营动作、不扣游戏时间、不改顾客期限。整个页面继续使用原有按行动推进的游戏时钟，不能变为现实秒数倒计时。
5. 底部状态栏固定；场景与人物同步淡入淡出，不做横向位移，转场结束才接受设施点击。
6. 保留铺务菜单中的“修缮与查铺”作为直接入口，进入同一设施区。箭头可键盘聚焦、Enter激活；Esc先关闭纸页，再返回柜台。淡入淡出为默认方式，不显示“简化切换”按钮。
7. 物品详情、议价输入、确认页展开时禁用边缘自动滑动，先关闭当前纸页；不得丢弃已输入的报价。危机、剧情或强制待办沿用既有优先处理流程，不允许导航绕过。

## 4. 设施点击和纸页

| 操作 | 反馈 |
| --- | --- |
| 指向设施 | 出现小纸签名称与低亮度边缘提示；不增加环境灯光 |
| 点击设施 | 在下方空地或设施旁展开一张纸页；同时只打开一张 |
| 点击其他设施 | 切换纸页；尚未提交的选择不扣钱、不耗时 |
| 点击空地或 Esc | 收起纸页 |
| 点击有效整修行动 | 明示价格、准备额度、实际效果；提交现有命令，成功后替换外观 |
| 条件不足 | 显示具体原因，如“现银不足40银元”“今夜准备已用完”；操作不可提交 |
| 写盘失败 | 沿用真实错误反馈，设施外观恢复到提交前状态 |

纸页位于中央下方，不遮住两侧设施与右侧出口；阅读账柜资料时会覆盖中央下半部，收起后可看完整柜号。实装宽405—510像素，最长内容在纸页内滚动，行动按钮可滚动到达。1280×720 下正文18像素，使用重新排版而不是整图缩小文字。

初次进入可短暂提示“指向物件查看，点击办理”，以后不常驻。设施名称不全部挂在画面上。

## 5. 一级设施独立成长

| 设施 | 初始外观 | 一级整修后 | 玩法约束 |
| --- | --- | --- | --- |
| 鉴物台 | 毡角破损、台面不平、灯座松动；基础工具已有 | 平整台面、补好支脚、换齐毡垫、固定台灯、工具入盘 | 40银元、准备1次；仅符合现有条件的普通工具检查10→5分钟 |
| 陈列柜 | 空柜、玻璃蒙尘、木框松动、搭扣破损 | 玻璃清楚、边框补牢、铰链完整，放置一块单件陈列衬垫 | 60银元、准备1次；一级1位，玩家亲自成交 |
| 旧账柜 | 账册杂乱、柜号可见 | 柜体可以修补变整洁；目录、核对标记、已查明柜格则另按真实调查进度叠加 | 探索免费；外观升级的取得方式另行设计 |

现有两项设施必须支持四种组合：两项未修、仅鉴物台已修、仅陈列柜已修、两项已修。后续旧账柜外观也应能独立组合；不能因购买鉴物台自动假定全铺翻新。墙面和地板保持建筑底色。本轮不自行添加整铺清洁费或将查账改成收费装修。

小修成功后可用短暂淡换、木器轻响表现修缮完成，不额外扣时间，也不强制播放长施工动画。表现动画不可造成重复提交。

基础工具即使设施未整修也继续可用。高级工具和二三级设施已有本轮概念效果图，实际仍属长期规划，未接入游戏；当前可运行版本不展示可购买的虚假入口。

## 6. 陈列和买家

- 空柜点击“选择陈列”，打开合格自有现货列表，包含缩略图、名称和玩家已知资料；不显示隐藏真值。
- 一级柜只有一个陈列位。选择后，该物品按真实外形绘制在玻璃之后，选择轮廓贴合实物，避免把整柜亮成灯箱。
- 开铺前可更换和撤下；营业时只允许沿用现有规则撤下，不通过新页面重新抽取买家。
- 已陈列页显示“陈列1/1”和货物名称；开铺后可提示“今夜已陈列”，不宣称一定有人买。
- 买家按原队列在柜台接待。设施区只复用已有来客通知，并提供返回柜台的入口，不在柜子旁新造第二套成交流程。
- 原渠道售出、撤下或货物失去资格时，及时移除实物并按原服务规则取消对应机会；不会复制库存。
- 已陈列跨夜保持；开铺、读档、进出场景不会重抽结果。页面动画不推进买家等待时间，实际游戏行动仍正常推进。

## 8. 美术分层与声音

资源拆分建议：

- 固定房间底图：墙体、地板、窗、柜墙后的建筑结构、柜台连接区域。
- 中央柜墙：初始／一级／二级／三级独立外观层；柜号与调查痕迹另层，外观改变不改探索结果。
- 鉴物台：初始／一级／二级／三级同锚点状态层，工具与知识材料另层；当前首批运行只使用已实现等级。
- 陈列柜：四阶段柜体、衬垫、陈列物、资料架、玻璃前景与柔和反光；分别支持规划的1／2／3位，没有独立高级灯具收益。
- 探索：目录、核对标记、夹板及调查后资料表现，均由真实进度控制。
- 光影：复用游戏时段明暗；灯光主要照台面，读字不依赖增加全屏亮度。
- 交互：热点、名称、按钮、状态栏、编号全部由引擎绘制，使用现有字体与纸纹。

环境可延续原雨声、低木响；悬停不反复敲响，打开纸页只用轻纸声。禁止用升级庆祝光束、大金币音或强烈闪烁破坏气氛。

正式画面需修正概念图底栏图标与字段错配、柜号细节；选择轮廓也应比概念图更克制。对比时先看同视角、同照明，避免用亮度变化冒充升级。

## 9. 实现顺序与验收

1. 绘制房间接缝和无文字底图；按四阶段设计准备设施独立状态、实际货物层与调查阶段层。旧账柜外观等级取得规则须先另行确定，当前首批不据概念图自动扩展玩法。
2. 接入双场景导航、边缘停留防误触、纸页位置和菜单直达；保留现有命令和服务。
3. 将整修、陈列、探索按钮接到现有规则与保存回滚，再补声音和小幅动态。
4. 1280×720、1600×900 实操：进入／返回、边缘快速掠过、反复切页、键盘返回、纸页展开时不会误滑。
5. 验证四种整修组合、无货／有货／撤下／另售、探索四阶段及跨夜恢复，视觉与真实状态相符。
6. 接待、危机、赎当、到期、03:00边界继续按现有规则，切换不重置队列、不暂停或额外推进游戏时钟。
7. 低分辨率检查物品识别、文字大小、按钮遮挡与柜号可读性；存档失败时画面与账目一起回滚。

本批已完成场景导航、一级局部外观、真实陈列物、调查后柜格、独立四阶段预览及双分辨率验证，详见本批验收。高级功能、中央账柜外观升级规则、专门施工动画和新增音效留待后续；本批整修成功立即更新外观。
