# 青花瓷整合发布 · v42

基于 main `4add7f1` 整合本轮青花玉壶春瓶开发与试玩修订，保留已上线的首债补救、凤镯预约、阿七提醒、插画开场、邻居教学与评弹收音机。

## 变化

- 青花玉壶春瓶支持元、明、清、民国年代判断，以及粗工、常品、精工判断；无隐藏修补玩法。生成时固定货值，手记、对客说法和客人认识分别保存。
- 补全四年代、两样本、两难度、三工艺的整器四向、绘纹、底足与柜台图样；柜台使用俯视及接触阴影。粗工以填色越界、边线及收边差异表达；常品、精工有各自细节。
- 删除多余灯光按钮，保留年代参考与换例图；工艺图录可切换整器、绘纹和底足并排比较。
- 认同但不降价时按原因回应：已计入货况、坚持要价、此前让价、最低筹款额或未形成进一步降价空间。仅改变回应，不改变相信概率、价格或固定实际价值。

## 入口与存档

默认新局：`porcelain_release`，内容／保存版本 42。自动槽 `auto/porcelain_release`，独立路径 `user://porcelain_release/autosave_v42.json`。

`play-unified.cmd` 启动正式新局；`play-unified.cmd -Stage porcelain -Wide` 或 `play-porcelain-v42.cmd -Stage porcelain -Wide` 启动隔离试玩。支持 `-Era yuan|ming|qing|republic`、`-Craft rough|standard|fine`、`-Sample 1|2`、`-Holder silk|factory|opera|antique|comprador`。

旧瓷器 v41 的 `porcelain_unified` manifest、存档路径和 `scenes/start_porcelain_v41.tscn` 保留；线上原 v41 首债入口保留为 `scenes/start_first_debt_recovery_v41.tscn`，其 manifest、规则与存档不改。新整合版使用最新首债事件与经营配置，只加入瓷器规则；新增运行的原有随机键归一到线上首债版本。
