# 《早绝的金镯》v28 剧情与实现

本地开发，基于 `6eb4fce`，默认运行 `first_debt_open`。本页描述本批内容；旧版使用自己的数据和存档，不补插本案。

## 案情与自然发现

二十年前，陈阿福为妻治病，将祖传龙凤金镯活当七夜，借十八银元。顾敬堂第五夜提前出售整对并改当期，第六夜陈阿福携钱来赎被拒。妻子后来病故，剧情不把改票直接归因为她的死亡。金镯的价值来自金料、工艺及成对保存，没有能力或致死禁忌。

所有票据固定使用「瑞字四十七」、旧历五月初一入当／初五出货／初六赎回被拒。首次旧票正文仅姓名、货物和借款额；主动细看才见五字下的七字残笔。两张纸同时读过后可托陈家口信，不需要买下凤镯。出货簿背页还有初五售镯收240、初六支付鬼市货款220的相邻记录，物名含糊，只留下用途疑问。

| 时点／场景 | 内容与意图 |
| --- | --- |
| 第十夜，合账并处理风险后 | 留下陈阿福旧票；不自动总结提前绝当 |
| 第十一夜起，普通来客 | 周成业带凤镯，走正常鉴货、问话与议价；旧包纸可以先看、后拒收 |
| 第十二夜起，普通交易 | 陈小满以缝补生计带绣样。自有凤镯会摆在柜边，她只说像家中旧物；柜里没有凤镯就不强行认物 |
| 陈家口信／认物后次夜 | 陈小满带来祖父旧记。核实姓名、票号与修补，补齐初六来赎的记载 |
| 看过工记，陆掌眼往来 | 卖货页出现托看龙镯的短对白，次夜可验配购买；银楼为正常持有人 |
| 三份资料读过，柜台会面 | 玩家自行说明事实，也可有意说谎或暂缓；不弹出“发现罪证” |
| 处理后次夜 | 原物路线谈镯匣，现金路线谈生活安排；不给能力、免息或免费物品 |

读纸、说明事实、收起和复看免费；托话、与陈小满核实、买龙镯、归还或赔偿各5分钟。普通鉴货、问来路、议价与出货维持原耗时。付款、交物可在同一夜连续办理，不额外按天拆链。

## 金钱与分支

| 处理 | 实际变化 | 后续 |
| --- | --- | --- |
| 买凤镯 | 开价120，最低100，真实库存一件 | 可追另一只或正常出售 |
| 买龙镯 | 180，无寻物费，真实库存一件 | 不产生再购买来源 |
| 陆掌眼收货 | 凤120／龙160／两只一起320 | 专项定价不加行情，卖出不清案 |
| 归还原物 | 两件从自有库存移出，成本核销 | 账旁记清 |
| 知情赔偿 | 扣300，金镯仍按实际持有状态保留 | 账旁记和，陈小满自主安排钱 |
| 暂缓或拒绝承担 | 无扣款、无报复、仍未了 | 可回头补办 |
| 知情说谎 | 只有明确虚假陈述记入选择历史 | 先说清隐瞒部分，再处理，无附加罚款 |

清与和互斥。告知实情与现金和解时，对话依据真实库存说明镯子仍在铺里、已卖出或尚未买下的下落。未调查、不肯接手或卖货本身不记说谎。已售原物不新增回购，但实际读过的资料保留，仍可赔偿。

## 来访与开放延续

首次未接待的卖家和陈小满顺延，仍占六个基础客位之一。接待后没有买镯，可在旧当铺册页的「翻查与托话」托口信，次夜补访不替换基础客人；遗漏可以重约。陈家核实会面不占普通交易位，普通客人、赎当、丈夫会面和风险优先。

十八夜只是内容节点，就寝风险与息费结清后才可主动结束。继续营业保留六位基础新客、行情、日结、赎当和常驻收货人；不新增第21夜还本。本案没有截止夜。主动结束保留当时未了／清／和状态，不称完整游戏终局。

## 阿七延续

第十一夜以后沿用获准陪伴、22:00离开、关铺离开和主动请走。未获准时可在空柜前简短再问，婉拒只记当天。新增绕细线、纸船、纸匣三段生活内容；阅读免费，首次写历史，复看不重复记录。她不认金镯、不交证据、不评价玩家结案选择，也不揭露与顾敬堂的关系。

## 实现边界

案件使用既有 `event_history`、`narrative_flags`、库存实例、流水和 `action_journal`。`FirstDebt.model`只读；`observe_document`验证实际可见性，`event_command`提交选择。打开册页、切换分类、总账本刷新与角色渲染不写已知标记；首次明确点击票面或「放大细看」通过既有观察命令记录发现，之后复看不重复写入。原子保存失败时整笔撤回，允许重试。

版本数据位于 `data/first_debt/`，旧v27文件冻结。新版本开放策略由 `first_debt_version`识别；事件支持同夜多个主动选择，解读与阶段由完整动作回放验证。v28开放回放取消4096条硬上限，仍逐条验证动作与最终状态。

## 资产说明

陈小满、凤镯、龙镯和工记／修补图是本批AI生成的可玩草图，保存在 `assets/first_debt/`。人物透明背景、手在画外，站在柜沿之后；不添加柜台外的新剧情页。

原画工具为内置 ImageGen。提示方向：民国旧当铺、成年缝补女工、干净素雅蓝衣、暖暗光、透明背景；两只旧金镯分别雕凤与龙，保持相配、磨损与真实金工；细节图参照凤镯原画，展示内圈瑞豐工记与凤尾旧焊口，不发光。细节引用原图生成后直接接入，没有脚本抠图或手工修改位图。

三份纸图由 `FirstDebtDocument` 使用游戏中文字体和纸张样式原生渲染，生成脚本为 `tests/first_debt_paper_assets.gd`。这样票号和日期不会由图片模型随机生成；游戏放大页面仍使用同源可读文字。临时资产身份只写在这里。

册页、纸质相角、陈家当票、出货凭据、家记封面及铜镜存根使用生成式图档草图，来源见 `assets/old_shop/SOURCE.md`；精确抄录仍来自冻结事件数据。新增显示资产不作为可交易物品。验收见 [册页报告](qa/old-shop-album/REPORT.md)。
