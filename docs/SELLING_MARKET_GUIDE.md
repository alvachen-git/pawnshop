# 批量卖货与陆掌眼行情（v12）

默认三夜游戏现已使用批量卖货。工作期间主目录同步到主线 8d3138b，本轮从同步前的备份恢复卖货改动，在隔离副本上整合；四夜普通交易样本仍使用独立入口及 v11 规则。

## 玩家操作

库存 → 卖货 → 选择买家 → 勾选货物 → 完成交易。选定买家后只显示该买家的货单，可更换买家、全选或取消。一次向一位买家交货，固定往返20分钟，不限件数；没有行走动画。看行情与选货不耗时。

货单列出每件报价、原始成本、差额及来源溢价；合计显示本次收入、成本、交易毛利和预计回店时刻。毛利不包含来源调查费与每日息费。完成后显示一张汇总凭据，逐件明细可滚动查看。

正在接待、在店等候以及待办赎当／续当的客人都会阻止提交，须先接待或送客。出货期间照常推进客流。买家窗口或封铺之前不足20分钟时，提前提示，不扣时间。

## 陆掌眼

街口替城中各家采办旧物的经纪人，首夜即可交易，每日18:00–03:00收货。只收眼下偏好的普通品类，不收鬼货。瓷器、金属器、首饰、钟表、文房和绣品分别由不同的外部托购消息带来。

基础报价为真实品相价值的140%，按既有规则四舍五入；已核实来源追加基础报价15%，向下取整。品相不构成拒收门槛，但瑕疵会降低真实价值。其他买家的报价倍率、介绍条件和营业窗口保留，生产配置中全部取消件数额度。

开局生成初始需求；每夜20:00–23:00之间产生一次新口信，时间按5分钟步长抽取。消息和时刻由本局种子固定，与玩家库存无关；新需求不重复上一种，直到下条口信生效前持续有效，跨夜保留。它不占剧情事件额度，不要求点击确认。柜台左下口信按钮显示最新品类并可直接进入卖货页，往来口信可在卖货页复查。

确认交易时锁定当趟行情；20分钟中途更换偏好不影响本趟，返回后显示新口信。

## 实现与存档

- `RunSession.sell_batch(buyer_id, item_ids)` 作为批量入口；新局原单件卖货入口也走同一校验。所有货物在扣时扣款前整体校验，失败不部分成交。
- 每件保留原销售记录及独立流水，批次保存共享编号、买家、货单、出发／结束时刻和行情编号。一次批次仅计一次行动。
- `MarketService` 使用独立种子序列生成行情，界面读取不改状态。存档根据当时行情、来客与行动历史复核销售。
- 新局 `save_version=12 / content_version=12`，默认 `user://p0/autosave_v12.json`。优先读本文件；没有时可读取旧v11、v10、v9文件，旧局继续使用其冻结内容与原卖货规则。想体验新卖货须选择新游戏。历史成交不重算，原文件不删除。
- 保留已发布v10的多种历史资金配置校验，以及v11三夜版与独立四夜样本；不把四夜样本替换为三夜版。

## 验证入口

- `tests/run_market.gd`：行情、批量、客人门槛、时间边界、品相与来源报价、重复提交、存档损坏及历史兼容。
- `tests/market_ui_smoke.gd`：真实鼠标操作，1280×720与1600×900画面和汇总凭据。
- `tests/market_checkpoint_process.gd`：write → next → read三个独立进程恢复。
- 统一Windows回归已纳入上述测试；沿用独立测试存档，不使用玩家进度。

固定种子经营样本使用可见证据压价、以已知估值下界报价、空柜时出售有正毛利的货。样本结果只能验证经营路径可执行，不能代替人工对节奏与难度的判断。具体结果见本目录交付验证记录。
