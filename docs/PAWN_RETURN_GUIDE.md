# 活当回访与夜末核票 · V06-Pawn.1

## 玩家流程

到期且会回访的原主在开铺时持票回店，按出票顺序优先接待。柜台显示当户、当票号、原物、本金、约定赎金及办理分钟。点击“验票收赎，交还原物”后，才收到赎金；测试续当约保留续当费和延期功能。账本只查账、导航，不直接收款。

回访期间不能接待新卖家、主动等待或关铺，免费查账与必要事件/危机仍可处理。普通新客的到达和离店时间按当日回访办理总分钟顺延。回访结束不会复制物品或重开旧交易。

到期无人来赎，封铺后逐张核票：

- 撕票留货：不进现金，原物以本金成本转现货，次夜可出售；历史当票仍可查。
- 折价转给同行：原物与当票一并交出，默认按本金八折向下取整，最低1银元。实收先入账，再付当夜息费；毛利为实收减本金。

选项先暂存，可来回修改；全部选完后才能统一合账、回房。失败时恢复现金、票据、权属、流水、息费和风险状态，保留草稿供重试。转当不清除封铺已经触发的危机或个人纠缠。
