## 可试玩内容

保留原三夜交易、铜镜收益与致命试验路线；新增固定寝屋、床、左侧命灯和书桌旧信。镜面在正面偏右预留，暂不承载玩法。财神香留在铺内。背景是程序绘制原型，不是最终美术；没有新增音效。

正常流程为：03:00封铺 → 合上账册（当票到期、息费入账）→ 铺内应对 → 回房 → 点击床并确认就寝 → 个人应对 → 等到天明 → 日结 → 次夜／三夜收尾。

无对应危机则直接进行下一步；书桌和命灯免费观察，旧信可跳过。房间没有普通库存、买家管理或解咒；03:00后不回到经营。未决危机期间不能通过床或转场跳过。

覆镜控制铺内风险。追看带来的纠缠到就寝阶段处理，卖镜也保留。两种问题同时发生时分开应对，不再合并成一次。危机优先于同夜经营失败：先结费用、应对风险，死亡只记绝当录；生还并完成睡眠后才判旧息费逾期，破产只记破铺录。

## 试玩评审重点

1. 不交易也能完成三夜：每夜现金92、84、76；读信、看灯、取消就寝均不扣费。
2. 回房后关程序，再从菜单读取：地点、时间、现金应保持一致。
3. 第三夜不覆镜，处理铺内危机后才出现回房；覆镜时可直接回房。
4. 追看旧当票，再覆镜或卖镜：铺内安静，但就寝仍有个人危机。
5. 危机前重启，仍须应对；应对/日结重启不重复扣款。死亡后菜单读档不能复活，只有一条本局终局记录。
6. 旧息费逾期且同夜追看：遇险先应对，死亡只写绝当录；生还睡至天明才因逾期写破铺录。
7. 1280×720与1600×900、当前电脑的显示缩放下，旧信、床确认和危机警告/两条选项均可读。

实际EXE完整试玩与DPI/其他电脑兼容仍由负责人确认；自动源工程窗口操作与包启动检查分别记录，不互相替代。
