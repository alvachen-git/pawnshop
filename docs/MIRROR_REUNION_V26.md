# v26 镜中重逢试玩说明

v26 `mirror_reunion_ten` 保留独立入口和存档；当前 main 默认入口为 v27，沿用本篇的铜镜规则。正式对质包括夫妻重逢、玩家交涉与四种收尾。2026-09-17 本地追加人物与告别演出打磨，不新增版本，详见 [演出试玩说明](MIRROR_PERFORMANCE.md)。v25及更早运行继续使用原规则。

## 启动

在 Windows PowerShell 中粘贴以下完整指令，无需更改系统脚本策略：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\tools\play_v26.cmd"
```

直接进入可正式对质的隔离测试局：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\tools\play_v26.cmd" -Stage ready
```

三个交涉后的阶段：

```powershell
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\tools\play_v26.cmd" -Stage apology
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\tools\play_v26.cmd" -Stage angry
& "C:\Users\alvachen\Documents\ChatGPT\pawnbroker\tools\play_v26.cmd" -Stage evasive -Wide
```

`apology` 是道歉后原谅；`angry` 可分别测试劝解与杀夫；`evasive` 是含糊后失望离去。默认1280×720，追加 `-Wide` 使用1600×900。测试资料使用独立 `.godot/test-appdata` 和 `user://tests/v26_preview/`，不修改正常玩家存档。首次生成、验证测试局需要等待，随后复用有效资料。追加 `-Check` 可检查启动后自动退出。

当前实现位于根目录下 `.tools/v25-playable` 工作区，根目录启动文件转发至该处。此工作区名称沿用上批目录，不表示启动旧版本。独立检出此源码时可直接使用其中 `tools/play_v26.cmd`；可通过 `-Godot` 指定 Godot 4.6.1 执行文件。

| 逼问为何不回家 | 60%道歉，40%被激怒 | 道歉后原谅；激怒后由玩家劝解或让女子杀夫 |

## 对话与结局通知

从柜前对话或物品记事点击“请镜中女子现身 · 5分钟”，立即完成现身并进入夫妻对白，不再要求第二次确认。收起后从库存提醒返回原页，不会重复现身或再次扣除已经花费的时间；旧档中已暂缓的阶段仍能继续。

双人立绘加底部姓名、逐句对白。丈夫沿用第三夜货郎外貌；夫妻使用统一水粉立绘，各有六种情绪状态；四条结局各有专属插画。当前说话者突出，选择集中显示。鼠标点击继续或确认键翻页，选择单独确认并有短暂防连点保护。

三个阶段各5分钟；翻页不额外耗时。结束阶段先读完剧情，再点击“结束这段对话”完成一次提交。阅读最终剧情时不会提前授予能力变化、资源或死亡记录；若保存失败，整段结局状态回滚，可重试。

对白中不写“镜子失效”“只剩铜胎”或怨气奖励。最后一段剧情读完且提交成功后，一次性结果通知才说明能力变化或怨气获得。库存与物品记事随后显示实际状态。重放、加载或重新打开记事不会再次弹出结果。

右上角只保留一个“收起 · Esc”，仅隐藏页面，通过库存惊叹号返回原阅读位置；右下角用紧凑的“继续 ▸”按钮翻页。对质中的所有分歧只显示实际剧情选择，不提供“改日再谈”。收起页面不会退出当前对质，也不推进时间、重置丈夫反应或重复收费。旧记录中的暂停动作仍可读取。已取得事实按实际历史写入分类记事，不收录照客流水或翻页操作。

## 自由节奏与保存

现实材料、已读查访回报与三次问答齐备，持有仍有能力的铜镜、丈夫正在柜前且无危机等阻碍时可正式对质。开始或恢复需有足够时间完成剩余阶段。开始前可推迟或不处理；对质中收起仅隐藏页面，不提供暂停分歧。第十夜仍结束试玩，第十一夜预约保留待办。

v26既有内容与自动入口独立；本次演出不增加存档字段或内容版本。原子提交与重放校验覆盖交涉、阶段、能力、人物死亡、怨气及通知依据。结束后丈夫的死亡只针对固定人物，不影响其他货郎模板，不走换物翌日死讯，也不写入玩家《绝当录》。
