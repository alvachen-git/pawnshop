# 旧账柜知识 · 首批顾砚生知识

日期：2026-09-22。已实现于本地v29，未推送或合并。

## 玩家操作

第二夜起，在开铺前进入铺内，鼠标移到旧账柜左上方第一柜时，柜门木纹会发亮，提示可以点击。柜面不写知识名字，点开后才显示“顾砚生知识”；选择“学习顾砚生知识 · 准备1次”，即掌握该项知识。

- 不收银元，不要求先修鉴物台、找工具册或探索第十七柜。
- 与其他准备共用每夜2次额度，开铺后不能学习。
- 已掌握后可随时免费复看；不能重复学习或再次扣准备。
- 顾砚生知识属于书画领域，只支撑他的扇画比对。仍须二级鉴物台和扇画工具；判断由玩家完成，不自动判真。
- 缺少知识时，保留检查破损、交易和收货后请行家鉴定。
- 查铺三步及其时间规则不变，知识学习不占探索进度。

## 扩展与兼容

知识采用稳定条目标识分别记录。`ShopKnowledgeService.TOPICS`登记名称、领域、对象、柜号、柜位、说明与用途，首项为`gu_yansheng`。将来可注册其他作者、器物或机械知识，并让对应玩法检查所需知识。仅注册条目不会自动实现新的鉴定玩法；目前只接入顾砚生。

新学习保存在`shop_growth.knowledge[条目标识]`，记录学习夜晚，用于准备计数。通过`growth_command("learn_knowledge", 条目标识)`沿用动作记录、原子保存与历史重放；旧存档缺少字典时按尚未学习读取。

旧v29已研习图录的记录只映射为“顾砚生知识已掌握”，不修改旧快照、不补扣准备；旧命令保留重放行为。仅找到旧册而未研习的，仍需到第一柜学习。v27/v28保持旧玩法。未知条目不能学习，伪造知识或学习夜晚会被重放校验拒绝。
