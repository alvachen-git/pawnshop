# 七夜整合版 v14

本文记录版本14的历史规则。当前默认新游戏使用版本16，继承第二夜起的准备并加入铜镜第一章，详见 [铜镜第一章](MIRROR_CHAPTER.md)。版本14通过旧存档或专用测试入口继续使用。

## 启动

版本14的完整流程可运行下列整合测试。默认标题及 Godot 编辑器 F5 已改为版本16。

运行定义 `integrated_seven`，内容和存档版本均为14。版本14通过独立清单加载；原三夜主场景、四夜、七夜经营与开场样板的清单保持不变。

## 一局中的内容

- 开场、银簪首单、首夜卧房接入同一条七夜流程，现银300，本金500，每夜息费5及铺费5。拒绝或错过银簪也能继续，后续买入其他物品不会被叙述成银簪成交。
- 每夜六个新客位置。第一夜首位是街坊妇人；第三夜时刻为18:00、19:30、21:00、22:30、00:00、01:00，第一位带铜镜，第五位触发旧当票。其余位置继续随机交易情境，第三夜活当样板保留第六夜赎当。
- 第四夜起开铺准备，第四、五夜钢笔机会，第六夜收货预约；第七夜结算保留库存、当票和债务，不提前还本。
- 批量交货往返20分钟。保留七夜普通买家，加入夜半收镜客（第三、四夜00:00–02:00，铜镜90银元）和开场街口银楼（沿用前三夜窗口，整合版改为20分钟批量交货）。不启用陆掌眼动态收货。

## 铜镜边界

窥镜5分钟只看见旧当票，不产生鉴定线索、图片、估价或折价收益；怀表依旧用正常机芯检查。追看再花5分钟，触发当夜个人应对。揭布5分钟、覆红10分钟；不必每夜重复覆盖已经盖好的镜子。

拒收、拒看、及时收手或卖镜均能继续经营。盖布与出售不会抹去当夜已招来的个人纠缠。之后只延续原有存放规则，本轮没有新的铜镜背景故事、持续收益或累积惩罚。首夜卧房普通旧镜与收购的泣血铜镜是不同物品。

## 存档与兼容

生产入口使用既有档案库 `user://save_library/library_v1.json`，自动位置为 `auto/integrated_seven`，手动位置仍为1–6；独立路径为 `user://integrated_seven/autosave_v14.json`。旧进度、旧物证和终局按原版清单还原，不迁移或覆盖。读取旧版不会改写标题入口的新游戏定义。

七夜编排新增显式剧情位置与固定时刻配置，旧版没有配置时沿用原生成结果。铜镜遭遇的空 `clue_id` 表示没有物证奖励，运行与存档回放共同校验。开场成交事件限定到首单来访，禁止拿后续收购冒充首单结果。
