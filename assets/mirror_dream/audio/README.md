- `door-sobbing.wav`：原录音前18秒，1700Hz低通、少量短反射、首尾0.7秒淡入淡出，轻微偏向门侧。没有变调、尖叫或配乐。游戏再降低音量，门前选择期间循环播放；收起仍继续，返回不重头播放。点击“出去看看”或“继续睡”、切换存档及离开事件时停止。
- 可复现处理：`tools/prepare_dream_cry.py`（numpy、soundfile）。这是授权现成的女性轻声哭泣录音，不是AI生成音频，也不以文字或合成蜂鸣代替。
