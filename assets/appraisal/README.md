## 提示词记录

各生成均实际附带对应图片参考。

- 桌面：以选定图为风格参考，生成1600×900旧木当铺鉴物桌；暖铜灯在右上、旧书与笔筒在上缘，中央和底部留空；手绘水粉、深棕旧毡，去掉折扇、打开的图录、所有文字和UI。
- 图录：参考选定图，生成约1100×760独立打开的纸本书，透明背景；左页有水墨山水扇面，标题说明留空；右上绘山脊转笔，右下绘被旧折磨断的“山”字；不烘焙标题与说明。运行中的书名、提示是动态界面文字，画作内字形保留在素材内。
- 真作：参考选定图，生成约1200×900独立展开折扇，透明背景、全扇骨与枢轴；山脊笔势流畅，题款纸墨共同老化。随后将题款局部明确为较大的“山”字，旧折横穿并磨断墨迹，保持扇形与山水布局。
- 临本：以真作图为编辑输入，保留轮廓、山水、题款位置和尺寸；仅使山脊轮廓出现等宽双重描线、停笔后再起，题款仍被同一旧折磨断。
- 后添款：以最终临本为编辑输入，保持同一大“山”字、布局、山脊与骨架；使山字在旧折交叉处被新黑墨接通，旧折在字两侧仍可见。

显示区域在`core/shop/fan_evidence.gd`以归一化坐标定义。局部放大直接使用整幅资源的`AtlasTexture`区域，选点与存档相对应；没有另外贴一张更明显的“答案图”。三种生成图有少量纹理变化，属于当前美术精修限制。
