# v27 发布验证

这是经本地试玩确认的独立版本；根目录原版不变，已有本地v26目录和旧存档不迁移。入口为根目录 `play-social-v27.cmd`，使用项目自带配置的 Godot 4.6.1 路径。

## 已实现

- 隐藏军阀关系与商誉，范围−100至100。商誉影响次夜普通散客，保留剧情、赎当和预约。
- 孙大元第二日柜台来访，三段交流后解锁《往来簿》。职务为营部军官，负责街面巡查与军需采办；玩家称孙长官。按其他客人重做半身比例，柜台前景遮挡腰部。
- 棉袄采购每次交三件自有现货，奖励50银元、关系+6；无期限，可立即重复接单。不接受在当物，重复提交不会重复发奖。
- 移除说情机会。保留保护费、付费解除停业或承受停业、六种特殊货源及旧主追索。
- 关系首次达到30获得永久照应牌，普通收购和活当每次接待可恐吓一次，要价底价降10%向上取整，商誉−1；原商誉比较基准不变。
- 新旧v27存档通过命令重放校验；介绍文案仅接受精确旧文本别名。旧局不重复结识，旧文件不改写。
