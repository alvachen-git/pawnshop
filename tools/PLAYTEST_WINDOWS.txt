鬼市当铺 · M8A.1 Windows 内部试玩

本包保留 M7「识货与识人」三夜内容。仅供内部测试，不是完整游戏。

启动
完整解压 ZIP 后，双击 Pawnshop.exe。Pawnshop.pck 必须与 EXE 放在同一目录。
无需安装 Godot，无需管理员权限。目标为 Windows x86_64，使用 Compatibility 渲染器。
本轮验证机器为 Windows 11；其他 Windows 版本、硬件及显示缩放尚未确认。
本包未做代码签名，Windows 或安全软件可能提示未知发布者。请核对可信来源与随包校验值；如仍被拦截，保留提示并反馈负责人，不要关闭杀毒软件或系统防护。

操作
鼠标点击柜台物件与按钮；滚轮浏览较长内容；报价栏支持键盘输入。
默认窗口 1280×720，也可调整至 1600×900。查看资料与现实思考不推进钟点，正式行动才耗时。
点击左上铺面招牌打开营业；点击客人后选择「对话／交易」，点击柜台货物后选择「鉴定」。左侧库存柜和桌上账本可直接打开对应功能。
先处理「铺中记事」，再开铺。右下角「菜单」分为「本局／铺务」：新游戏与读取夜末存档在本局，夜间结算等入口在铺务。一次只开一个游戏窗口。

保存
存档格式 v7，内容版本 8。日结、夜间应对、进入下一夜及收尾时保存，夜内交易不即时保存。
存档位置：%APPDATA%/GhostMarketPawnshop-M8A/p0/autosave_v7.json
游戏日志：%APPDATA%/GhostMarketPawnshop-M8A/logs/godot.log
将上述目录粘贴到资源管理器地址栏即可查找。
测试包与编辑器版本存档隔离，不自动复制开发版进度或历史账册。
